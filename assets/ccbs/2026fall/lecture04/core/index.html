Dynamics: local stability, phase portraits, bifurcations

Use geometry to compress whole families of trajectories, then keep the chemical state space and the theorem behind every picture visible.

CCBS · EST 5053 · Fall 2026 · lecture 4 · core page (full) · 2026-09-10 (Thu) 10:40–12:15 · students present, lecturer-backed

Lecture 3 built the vector field. This lecture asks what survives when parameters and initial conditions change. A phase portrait replaces one computed time course with fixed points, basins, separatrices, and recurrent behavior, a geometry that also connects regulatory dynamics to persistent phenotypes.2 The central rule is evidential: the drawing is never the first link. It follows from a model, an invariant state space, and a theorem or reproducible calculation.

The deliverable

By the end of 95 minutes, the room should be able to draw and read a phase line, classify a saddle-node correctly, construct a two-variable portrait from nullclines, compute and interpret a Jacobian, use trace and determinant without over-claiming, and state why chemistry and dimension restrict the possible portrait.

Part 1

Read motion without solving

In one dimension, signs and ordering already give a complete qualitative grammar.

1State, flow, and phase line

A state contains enough information to determine the future. A phase portrait shows the velocity attached to every admissible state.

Write an autonomous model as ẋ=f(x;k). A trajectory x(t) is one solution; the flow is the family of all solutions. Autonomy means that the arrow at a state is single-valued. If an input protocol or temperature changes explicitly with time, write f(x,t) or promote that input to a state.

For scalar ẋ=f(x):

  1. Find every root x* satisfying f(x*)=0.
  2. Evaluate the sign of f in each interval between roots.
  3. Draw a right arrow for f>0 and a left arrow for f<0.
  4. Call a root attracting if both neighboring arrows point toward it and repelling if both point away. For a simple root, this is equivalent to f′(x*)<0 or f′(x*)>0.

The 2025 Lecture 3 packet develops the same sequence from phase lines through two-dimensional linearization.1

Stability has two clauses

Lyapunov stability means every sufficiently small initial displacement remains small. Attraction means nearby trajectories converge to the fixed point. Asymptotic stability requires both. The arrow test around a simple scalar root with f′(x*)<0 gives asymptotic stability; saying only “stable because trajectories converge” silently drops the first clause.

Two exact checks from the 2025 board

Regular attraction

ẋ=−x separates to d(log|x|)/dt=−1, hence x(t)=x0e−t. The arrows, exact solution, and one-unit relaxation time agree.

Finite-time escape

ẋ=x2 gives x(t)=x0/(1−x0t). For x0>0, it diverges at t=1/x0. A phase line gets the direction right but does not reveal this clock.

2One dimension can switch

“No cycles” is not “no decisions.” A scalar autonomous equation can be bistable.

Use a concentration-compatible teaching example:

ẋ=−(x−1)(x−2)(x−3),    x≥0. (1)

Test the four intervals:

intervalsign of ẋmotionconsequence
0≤x<1+righttoward 1
1<x<2−lefttoward 1
2<x<3+righttoward 3
x>3−lefttoward 3

Thus 1 and 3 are stable, 2 is unstable, and the initial condition chooses the final state. This is the geometric skeleton of a toggle. A biological implementation may need hidden promoter or regulator states to generate the cubic effective production law, but the scalar phase line itself is not forbidden.

By contrast, no nonconstant scalar trajectory can return to its earlier state. If it did, uniqueness would force the same future from that point, while strict ordering would require a crossing. The correct boundary is: one-dimensional autonomous flows can switch, but cannot sustain oscillation.

Room check, 90 seconds. For ẋ=x(1−x)(x−0.2) on x≥0, identify the stable roots without differentiating. Then say which initial conditions reach each one.

3Saddle-node birth and critical slowing

A bifurcation is a change in the portrait's topology. Near a saddle-node, recovery slows because the restoring eigenvalue approaches zero.

Choose the normal form

ẋ=r−x2. (2)
  1. Set ẋ=0: x*=±√r for r>0, one double root for r=0, and no real root for r<0.
  2. Differentiate: f′(x)=−2x.
  3. At +√r, the derivative is negative, so the branch is stable.
  4. At −√r, it is positive, so the branch is unstable.

The signed coordinate x is a local deviation from a physical concentration, so the negative branch need not mean a negative molecule count. This sign convention repairs the common error of calling both branches stable.

Linearize about the stable branch: u̇=−2√ru. Its relaxation time is

τ=1/(2√r). (3)

At r=1, τ=0.5. At r=0.01, τ=5. A hundredfold approach in the parameter produces a tenfold slowing. This is a measurable warning of proximity to the bifurcation, provided noise and the local normal form are handled honestly.

Part 2

Build a phase portrait

Nullclines locate equilibria and partition directions. The Jacobian classifies each intersection locally.

4Nullclines, step by step: a toggle

An x-nullcline says where horizontal motion pauses. A y-nullcline says where vertical motion pauses. Only their intersections are equilibria.

Use a symmetric mutual-repression model:

ẋ=4/(1+y2)−x,    ẏ=4/(1+x2)−y. (4)
  1. Set ẋ=0: x=4/(1+y2).
  2. Set ẏ=0: y=4/(1+x2).
  3. Plot both in the nonnegative quadrant. The intersections are (2−√3,2+√3), (1.3788,1.3788), and the reflected outer point.
  4. Test one point in every region. Below the x-nullcline, ẋ>0; above it, ẋ<0. Apply the analogous rule to y.
  5. The middle saddle's stable manifold is the basin boundary. In this symmetric model it lies on x=y.

Working phase portrait · click to launch a trajectory

The equations are exactly (4). Nullclines and the separatrix are fixed; each click supplies a new initial condition. Use this before writing code to predict which expression state wins.

Click inside the square. The final point will be classified by its nearest stable equilibrium.

The synthetic toggle built by Gardner, Cantor, and Collins realizes mutual repression experimentally and makes hysteresis a design and measurement target.3 The nullcline diagram predicts two distinct inducer sweeps: increasing and decreasing input cross different basin boundaries.

5The Jacobian as a local microscope

Linearization keeps the first derivative of the vector field near one equilibrium. It does not replace the nonlinear system globally.

Write u=x−x*. Taylor expansion gives

u̇=J(x*)u+O(‖u‖2),    Jij=∂fi/∂xj. (5)

Differentiate (4) entry by entry:

J(x,y) = [ −1    −8y/(1+y2)2
−8x/(1+x2)2    −1 ]. (6)
equilibriumeigenvalueslocal conclusion
(0.2679,3.7321)−0.5, −1.5stable node
(1.3788,1.3788)+0.3106, −2.3106saddle
(3.7321,0.2679)−0.5, −1.5stable node

The calculation confirms the arrow picture. Local eigenvectors at the saddle give the tangent directions of its stable and unstable manifolds. To find the global separatrix in a nonsymmetric model, integrate backward from tiny offsets along the stable direction or use a boundary-value continuation method.

Room check, 2 minutes. Point to every minus sign in (6) and explain it biologically. The diagonal terms are loss; each negative off-diagonal term is repression by the other species.

6Trace, determinant, discriminant

For a real two-by-two Jacobian, three scalar combinations locate every hyperbolic local shape.

λ2−τλ+Δ=0,   τ=tr(J),   Δ=det(J),   D=τ2−4Δ. (7)
conditioneigenvalueslocal shape
Δ<0real, opposite signssaddle, unstable
Δ>0, D>0, τ<0real, both negativestable node
Δ>0, D<0, τ<0complex, negative real partstable spiral
Δ>0, τ>0positive real partunstable node or spiral

Example: A=[[-1,−2],[1,−1]] has τ=−2, Δ=3, and D=−8. Its eigenvalues are −1±i√2, so trajectories spiral inward. The imaginary part sets angular frequency; the real part sets exponential envelope.

7The nonhyperbolic warning

Purely imaginary linear eigenvalues mean “first order is silent,” not “the nonlinear system is a center.”

Compare three planar systems in polar coordinates:

(a)   ṙ=−r3,   θ̇=1    (asymptotically stable)
(b)   ṙ=0,   θ̇=1    (center)
(c)   ṙ=+r3,   θ̇=1    (unstable). (8)

All three have the same Jacobian at the origin and the same eigenvalues ±i. Cubic terms decide three different outcomes. A conserved energy proves a center for an ideal mass–spring oscillator; linearization alone does not. The Hartman–Grobman guarantee applies only to hyperbolic equilibria, where no eigenvalue has zero real part.

The spring calculation supplies the missing evidence

For displacement q, velocity v, mass m, spring constant k, and drag c,

q̇=v,    mv̇=−kq−cv,    E=(mv2+kq2)/2,    Ė=−cv2. (9)

When c=0, every trajectory stays on a constant-energy ellipse: that conserved quantity proves a center. When c>0, energy falls unless v=0; the ellipses shrink into an attracting spiral. This is a global argument about the actual system, not a guess from one simulated orbit.

A presentation trap

Do not call a closed-looking numerical curve a limit cycle. Integrate longer, halve the solver step, perturb the initial state, and check whether trajectories converge to the same orbit. A center is a continuum of neutrally stable closed orbits; a stable limit cycle is one attracting orbit.

Part 3

Chemistry constrains geometry

Dimension limits which global theorems apply. Stoichiometry and reaction structure limit which vector fields are realizable.

8Cycles and the dimension boundary

Poincaré–Bendixson is a planar theorem. The repressilator is a three-variable negative-feedback loop.

For a smooth planar system, if a trajectory remains in a compact region and its limiting set contains no equilibrium, Poincaré–Bendixson restricts the recurrent limit to a periodic orbit. This yields a useful proof pattern: construct a trapping region, exclude equilibria from the limiting set, then infer a cycle.

The repressilator instead closes a ring of three repressors:

ṗi=α/[1+pi−1n]−pi,    i=1,2,3  (cyclic). (10)

It lives in three dimensions even before mRNA states are added, so the planar theorem does not apply directly. Elowitz and Leibler built the original circuit and observed noisy oscillations.4 A later redesign produced synchronous long-term oscillations by changing degradation and noise propagation while retaining the ring logic.5 Topology creates a possibility; kinetics and implementation decide whether it is realized.

9What chemical reaction networks may do

A CRN is not an arbitrary polynomial ODE. Positivity, conservation, reaction signs, and structural theorems remove possibilities before parameter fitting.

The quickest realizability test lives on the boundary. If xj=0, a physically admissible concentration field must satisfy fj(x)≥0. In an elementary mass-action network, every reaction that consumes Xj contains at least one factor of xj, so that consumption rate vanishes on the boundary. Production may remain positive; loss may not push the state outside the orthant.

Room check, 90 seconds. At x=0, test ẋ=1−x2, ẋ=x2−1, and ẋ=x(1−x). Which can preserve x≥0? This boundary test is necessary for concentration dynamics; by itself it is not a complete CRN realization theorem.

Horn and Jackson's complex-balanced theory excludes oscillation and multistability within its positive compatibility classes.6 Sontag's monotone-systems review shows why dimensions above two are not analytically hopeless.7 Conversely, a feedback cartoon does not guarantee bistability; elementary reaction structure can rule it out.8

Two corrections carried over from the research essay
  1. Parameter uncertainty is not “all rate constants must be unequal.” Independently generated rates may happen to coincide. The modeling warning is that an exact cancellation is not robust unless a shared mechanism enforces it.
  2. High dimension is not “nothing useful can be said.” A complete phase-plane drawing is lost, but conservation, complex balance, monotonicity, injectivity, Lyapunov functions, and bifurcation theory still support global conclusions when their hypotheses hold.

Part 4

Teach and extend

The core page gives a complete portrait-building workflow. Extensions should change one theorem, mechanism, or dimension at a time.

10The core story and beyond

Geometry earns trust by keeping its domain, its theorem, and its approximation visible.

The story in seven sentences
  1. An autonomous vector field assigns one velocity to each state.
  2. In one dimension, root ordering and arrow signs determine every fate; bistability is possible and cycles are not.
  3. A saddle-node creates or destroys one stable and one unstable branch, with recovery slowing near collision.
  4. In two dimensions, nullclines locate candidate equilibria and arrow signs assemble the portrait.
  5. The Jacobian classifies a hyperbolic equilibrium locally; trace and determinant compress that calculation.
  6. Nonhyperbolic points and global cycles require additional arguments.
  7. For biochemical systems, positivity, stoichiometry, and reaction structure restrict the portrait before simulation begins.

A student team can start in twenty minutes

  1. Write the claim. Choose one sentence: “this model switches,” “this equilibrium is locally stable,” or “this orbit attracts.” Do not begin with a plot.
  2. Declare the state space. List variables, units, nonnegative or signed domains, conserved totals, and the parameter being varied.
  3. Do the geometry by hand. Find scalar roots or planar nullclines, mark signs, and predict equilibria and basins before simulation.
  4. Do the local calculation. Evaluate the Jacobian at every equilibrium and record eigenvalues, eigenvectors, and whether hyperbolicity holds.
  5. Make one reproducible figure. Plot a vector field plus several trajectories from stated initial conditions; show nullclines and fixed points on the same axes.
  6. Try to break the claim. Double the integration horizon, halve the step size, perturb both initial conditions and parameters, and identify which conclusion survives.
Minimum handoff at the end of the first work session

One model equation with units, one annotated portrait, one equilibrium table, one explicit theorem or numerical-evidence label, and one failed or surviving stress test. That package is enough for another team member to reproduce the argument and improve it.
