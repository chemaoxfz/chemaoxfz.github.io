Perturbations distinguish mechanisms of adaptation

An input step can leave several adaptive mechanisms indistinguishable. A specified output load can separate their predictions. The inference depends on the measured output, the fixed reference and the operating range.

CCBS 2026 · Research essay for Lecture 10 · 12 October 2026

The same return to baseline can arise from different mechanisms. An incoherent feedforward loop can cancel the input at steady state. An integral controller can also return to baseline by accumulating the output error. A persistent input step establishes adaptation in both cases. To distinguish these mechanisms, perturb a process for which their predictions differ.

A first-order load on the output separates the two models compared here. The load changes the output equation of both models. In the incoherent feedforward loop it also changes the error-integrating identity, so the adapted output becomes input dependent. In the integral controller it leaves the controller identity intact, so a feasible, attracting rest retains the same reference value. The calculation is developed in §5.

A robustness claim must specify what is allowed to change. Alongside the observable and the disturbance class, specify the changes of the system under which the claimed property persists. We call these changes the robustness class. Preserving input invariance and preserving the reference value are different requirements. Section 1 defines both before comparing the literature.

The claim has a stated reach. For the candidate models specified below, displayed algebra establishes the predictions and numerical calculations check their implementation. Beyond those models it holds only where a theorem's hypotheses hold: Francis and Wonham's for linear regulators,7 and three later theorems for reaction networks, each under its own. It does not prove that every adaptive network has a physical feedback edge, nor that its memory integrates the error with a constant gain. A chosen change discriminates specified candidates. It does not by itself locate a molecule or recover a network.

Part I

What a robustness claim names

The three things every claim of robust perfect adaptation fixes, and what a memory reads on one simple plant.

1Specify the observable, disturbances and allowed changes

A claim that an output adapts robustly is complete only when it names the output, the inputs it adapts to, and the changes the adaptation survives. Published claims name different ones.

Adaptation is read from a step experiment, and the experiment already fixes two of the three named things. Hold an input at one level until the system rests, step it to another level, and hold it there. The output responds and then returns to its old value while the input stays at its new one. The quantity that is said to return is the claim's observable. The set of inputs, or more generally of constant disturbances, it returns from is the claim's disturbance class. A claim of perfect adaptation says that the steady output is the same for every disturbance in that class.

The observable is a choice, and one network can give three different answers. The Lecture 10 core's two-cycle feedback circuit shows it. An input I modifies a protein A to its active form A∗A^*, which modifies a protein B to B∗B^*. The active B∗B^* returns A∗A^* to A, and a fixed enzyme E returns B∗B^* to B. Every enzyme-substrate complex is kept: C3C_3 is A∗A^* bound to its substrate B, C2C_2 is A∗A^* bound to B∗B^*, the complex that carries most of the memory, and C4C_4 is B∗B^* bound to E. The ratios need nonzero outputs at u0u_0, before and after the change. A design tolerates the change when Δ=0\Delta = 0 and ε(u)=0\varepsilon(u) = 0 for every uu in UU. A design whose input dependence stays zero while Δ≠0\Delta \neq 0 is input invariant with a moved set point.

Two conventions for the numbers follow from the definition. Every Δ\Delta and ε\varepsilon in Part III is a ratio of positive outputs: a concentration, an activity or a set point of 1. An output whose set point is zero, such as a signed deviation, takes differences instead. The demo of Section 2 reports the deviation x∗=X∗−1x^* = X^* - 1, which equals Δ\Delta there because the old set point is 1.

The thesis concerns tolerance in this strict sense. Under the first meaning of "robust", designs with no memory of the error survive changes downstream of the input. The next section shows a subtractive compensator that stays input invariant under any load, and Section 5 shows an incoherent feedforward loop that stays input invariant when its output's removal constant changes. In both, only the set point moves. A claim that the return survives a change therefore says, in this essay, that the output returns to the same set point after the change, at every input of its class.

Two kinds of evidence carry the tolerance claims that follow. A universal statement, true for every input or every value of a constant, rests on displayed algebra: each design's steady output written as a function of its input and constants. The finite numerical checks of Part III, at one input pair or on a grid, illustrate that algebra and test the code that draws the figures. They prove nothing on their own.

2Compare input cancellation with error correction

One plant, three designs. What each design's memory reads, the input or the output's error, decides which changes it can answer.

When a persistent step moves the vector field off the old rest and the output still returns, the input is held in some other state. The Lecture 10 core gives the bookkeeping for models that settle with the output read from their state: the old rest is no longer a rest, the output is the same at the new one, so some other state differs (core §1). Call that state the memory. At rest it holds the action that cancels the input, in the controller's own units, not the input itself (core §2). A matched subtractive compensator is the exception: it cancels the step inside the same rate equation, so the vector field never moves and no other state has to change. What decides which changes a design survives is what its memory, or its compensation, reads.

Write the core's simplest plant in absolute units, so that a load and a removal rate have meaning. Measure the output XX in units of its set point. Let the plant make XX at a basal rate γ0=1\gamma_0 = 1, add an input dd to that production, and remove XX at rate γ\gamma plus an optional first-order load ℓ\ell. A controller adds its action uu:

Part II

Two theorems, two sets of hypotheses

The classical internal model principle takes a robustness class as a hypothesis. A later theorem drops it, and finds an internal model without saying where it sits.

3Robust regulation requires an internal model under stated hypotheses

Francis and Wonham's internal model principle requires an error-driven model of the disturbance only because it asks regulation to survive a stated class of plant changes. A smaller class asks for less.

The principle answers the question of necessity for linear regulators, under four hypotheses. Francis and Wonham pose the classical regulator problem "in the context of linear, time-invariant, finite-dimensional, multivariable systems": a plant, a separate compensator, and disturbance and reference signals produced by a known generator (p. 457).7 The compensator processes plant measurements, the reference, "and possibly the feedforward disturbance signal" (p. 457). It must keep the closed loop stable and drive the regulated error to zero, and a synthesis is called structurally stable when both properties "are preserved when certain system parameters are perturbed" (p. 457). In classroom form the hypotheses are a linear plant, a known class of signals, a stable loop, and regulation that survives small changes of the plant.

Under those hypotheses the controller must feed back the regulated variable and carry a model of the signals in that feedback path. Their Theorem 2 reads: "The synthesis is structurally stable at A3A_3 only if the compensator incorporates an internal model of A2A_2", where A2A_2 generates the exogenous signals and A3A_3 holds the plant parameters allowed to vary (p. 460). For steps the generator is w˙=0\dot w = 0 and the model is an integrator (p. 461). The principle as they state it: "A regulator synthesis is structurally stable only if the controller utilizes feedback of the regulated variable, and incorporates in the feedback path a suitably reduplicated model of the dynamic structure of the exogenous signals" (p. 460).

The robustness class is part of the theorem, and the authors say that shrinking it shrinks the requirement. Directly after Theorem 2 they write: "if some of the elements of A3A_3 are not subject to variation then it may be that a full internal model is not required: a smaller class of parameter variations in general requires less reduplication in the internal model" (p. 460). This is the thesis of this essay in the theorem's own setting. The class of changes the regulation must survive decides how much internal model is needed and that it sits in the error's feedback path.

Model 1 shows the two ends of that statement. The compensator of Section 2 reads the disturbance itself, the feedforward signal the theorem allows, and with a fixed plant it needs no internal model: its rest is input invariant at every dd. It fails as soon as the plant may change, because its rest 1/(γ+ℓ)1/(\gamma+\ell) moves with the removal. The integral design has the error-driven integrator that the theorem demands for steps, and its rest X∗=1X^* = 1 survives every change of γ\gamma and ℓ\ell that keeps the loop stable. Francis and Wonham also note what a damaged internal model costs. A slightly perturbed integrator leaves "a small steady state offset error", and "the accuracy of regulation depends on the fidelity of the internal model" (p. 461). That is the leak that growth dilution adds to a chemical memory in Section 6.

The hypotheses limit where the theorem applies. It is linear, its perturbations are small, the regulated variable must be readable from the measurements, and a technical condition restricts what the compensator learns from the disturbance directly (p. 460). The extension to nonlinear plants is local, with constant signals (p. 462). A chemical network that adapts may or may not meet these hypotheses, and each case must be checked before the theorem is invoked.

State the robustness class a regulator claim assumes, and the internal model the linear theorem then demands: for constant disturbances and small changes of the plant, an integrator of the regulated error in the feedback path. Check the theorem's hypotheses before applying it to a network.

4An internal model can be a combination of states

A theorem without a robustness hypothesis still finds an internal model in any adapting system that meets its conditions. It does not say whether that model is a separate controller, and the incoherent feedforward loop shows why it cannot.

Sontag's theorem reaches an internal model from adaptation itself, with no plant-controller split and no robustness requirement. He notes that the Francis and Wonham theory "applies to systems Σ which are already partitioned into a 'plant' plus a 'controller'" (p. 120).11 Some extra condition is still needed, because a system that "simply outputs y = 0 for every possible input signal u does not contain any subsystem generating the signals u" (p. 120). His condition is signal detection: "the output must reflect sudden changes in the input" (p. 120), stated precisely as a uniform relative degree. Under it, with bounded trajectories and a class of signals from a Poisson-stable generator, the system "contains an output-driven internal model" of the signals (Theorem 1, p. 124). The theorem also assumes that certain vector fields constructed from the system are complete and commute with each other (Assumptions 2 and 3, p. 123), which supply global coordinates. Sontag notes that these hold automatically for linear systems and are "quite strong" for nonlinear ones (Remark 3.2, p. 125).

His own chemotaxis example finds the integrator as a combination of states. In a receptor model with unbound and bound receptors x1x_1 and x2x_2, the combination B=x1+x2B = x_1 + x_2 obeys B˙=y\dot B = y, which he calls "an integrator (internal model of a system which produces constant inputs) driven by the output y" (p. 124). No molecule is that integrator. It is found by a change of coordinates.

The linear necessity argument of Yi and colleagues also produces a coordinate, not a controller. They show that "robust asymptotic tracking, tracking that holds for parameter variations as well as input variations, holds if and only if integral control is a structural property of the system" (p. 4653).12 The proof linearizes, x˙=Ax+bu\dot x = Ax + bu and y=cx+duy = cx + du, and uses the zero steady gain d−cA−1b=0d - cA^{-1}b = 0 to find a row vector kk with k[A b]=[c d]k[A\ b] = [c\ d], so that z=kxz = kx obeys z˙=y\dot z = y (p. 4653). Any linear system whose steady gain vanishes has such a coordinate, including the linearization of an incoherent feedforward loop.

The incoherent feedforward loop of the core has exactly such a coordinate. In the loop x˙1=k1w−δx1x2\dot x_1 = k_1 w - \delta x_1 x_2, x˙2=k2w−γx2\dot x_2 = k_2 w - \gamma x_2, the combination z=x1−(k1/k2) x2z = x_1 - (k_1/k_2)\,x_2 obeys

z˙=δx2 (x1∗−x1),x1∗=k1γk2δ,\dot z = \delta x_2\,\big(x_1^* - x_1\big),\qquad x_1^* = \frac{k_1\gamma}{k_2\delta},(4)

an integral of the output's error with a positive gain that depends on the state (core §10). Xiao and Doyle give the same construction for the sniffer, "z acts as a constrained integral variable" (p. 4).13 The coordinate fits Sontag's output-driven form, although his Assumptions 2 and 3 have not been checked for this loop (core A1). The identity (4) holds directly, without the theorem. Araujo and Liotta likewise call the feedforward balancing mechanism "a form of integral control that is distinct from the integral feedback control" of their opposer modules (p. 5).4

The identity is weighted in laboratory time. Set τ(t)=∫0tδx2(s) ds\tau(t)=\int_0^t\delta x_2(s)\,ds. Wherever the degrader is positive, equation (4) becomes dz/dτ=x1∗−x1dz/d\tau=x_1^*-x_1. The change of clock exposes the integral structure. It does not add a molecular feedback edge or establish every hypothesis of an internal-model theorem.

So "the memory integrates the output's error" does not by itself separate feedback from feedforward. Both designs integrate an error somewhere. What separates them is which changes the integral relation survives. Xiao and Doyle state the criterion: a system has perfect adaptation "for all uncertain dynamics that keep the system stable and the integral variable z unchanged" (p. 3), and the property is "naturally robust to uncertainties that preserve stability of the system and structure of the integral variable" (p. 8). The robustness class therefore determines which of these candidate identities survives the specified changes. Part III computes that for the core's designs.

Tell what an internal-model theorem locates from what it only asserts exists. For an adaptive model, find the coordinate whose rate is a function of the output's error, write its identity, and ask which changes leave that identity intact.

5A first-order load separates the two adaptive mechanisms

The incoherent feedforward loop's coordinate's identity contains the output's own removal law. A first-order load on the output adds a term to it and breaks it, while the sequestering pair's identity contains no plant term and survives.

A change of the output's removal constant keeps the incoherent feedforward loop's identity's form. In equation (4) the rate constant δ\delta of the output's removal by the degrader appears twice, in the gain and in x1∗=k1γ/(k2δ)x_1^* = k_1\gamma/(k_2\delta). Doubling δ\delta changes both, and the identity still says that zz rests only where x1=x1∗x_1 = x_1^*. So the loop stays input invariant for every input w>0w > 0 while its set point halves. In the language of Section 1, the change leaves ε(u)=0\varepsilon(u) = 0 and makes Δ=−50%\Delta = -50\%.

7Separate model discrimination from a necessity theorem

The conclusion holds at three strengths: established among the candidate designs, a theorem beyond them only under named hypotheses, and never a location of a molecule or a network.

Among the core's designs the conclusion is established by algebra and checked by computation. The designs that tolerate a plant change or a first-order load are exactly those whose memory identity contains no rate law of the plant: equations (3) and (7), and the chemotaxis rest a∗a^*. The feedforward designs carry input invariance through a coordinate or a measurement, and lose the set point under the same changes. This is an inference among specified candidate mechanisms under declared perturbations.

Beyond the candidates, four theorems extend it, each only under its own hypotheses. Francis and Wonham's principle covers linear regulators that see the regulated error, with small changes of the plant (Section 3).7 Araujo and Liotta show that a network whose stimulus enters at the output node itself "cannot invoke the balancing mechanism to achieve RPA, and must instead rely on opposition" (p. 4, and their Corollary 2, SI p. 13).4 A first-order load is such a stimulus, so in their topological setting only the error-integrating opposer module can tolerate it. Gupta and Khammash's criterion covers the largest robustness class in mass-action networks, under the hypotheses stated in Section 5.10 Hirono, Gupta and Khammash show that integral feedback "is necessary (and sufficient) for kinetics-independent RPA in deterministic chemical reaction systems" (p. 013017-25), where kinetics-independent means that adaptation survives any change of the rate laws that keeps the system stable (p. 013017-7).14 Hirono and colleagues also say that the internal model principle is a family of results, not one: "There can be several instantiations of the IMP depending on the type of disturbances allowed and the nature of the robustness desired" (p. 013017-12).

An error integral may be weighted or approximate, and the claim allows both. Yi and colleagues' chemotaxis coordinate is a weighted approximation to total methylation, valid under four assumptions (pp. 4650–4651).12 The incoherent feedforward loop's coordinate's gain δx2\delta x_2 and Gupta and Khammash's factor m1(x)m_1(x) depend on the state. The core's zero-order integrators hold only inside a regime of saturated enzymes (core §5 and §6). None of the conclusions here needs a constant gain or a single molecule that integrates.

A chosen change discriminates candidates. It does not locate a molecule or a network. Model 1's integral memory, the chemotaxis methylation and the sequestering pair behave alike in every column of Figure 2 where each is defined. They tolerate the input step, the plant change and, where it is defined, the load. A reference change moves the set point of each, and dilution, where it is defined, breaks each. The robustness class cannot tell them apart. That takes experiments of another kind: removing the memory, as a cheR deletion does, or pushing the input past the memory's range (core §10).

A failed recovery is evidence against a feedback memory only when the mechanism's own conditions held. A feedback design can fail to return to its set point after a load for three reasons that leave its identity exact, and a fourth that changes it. The new rest may need a negative actuator, so that a controller pool grows without bound (core §7, windup). The rest may be unstable: with an mRNA stage the core's annihilation controller, at annihilation constant η=100\eta = 100, is unstable for actuation gains from 2.0038 to 49.904 (core §7). The actuator may saturate. These three leave the identity exact. Leakage is different: dilution adds a term to the identity itself, as in Section 6. The refutation criteria below are stated with those conditions in place.

What would refute the thesis, claim by claim

Among the candidates. A design among the six whose return survives a first-order output load while its memory identity contains the output's removal law, or one that fails a plant change while its identity contains no plant rate law and its rest is feasible and stable. Either would contradict equations (3), (6) and (7).

Beyond the candidates. A network that meets the hypotheses of one of the theorems of this section and tolerates a first-order load, or the changes its theorem names, with no combination whose identity is free of the changed rate laws.

In the literature. A measured response that contradicts a named fitted model with that model's conditions checked: a set point that holds under a first-order load in a system fitted by a feedforward model whose coordinate contains the output's removal, or a set point that moves under such a load in a system fitted by an error-integrating controller whose rest was feasible, stable and unsaturated and whose leakage was negligible. Such a response challenges that fitted model, not every network given the same label.

State the necessity of a memory with its strength: established among named candidates, a theorem under named hypotheses, or neither. Before reading a failed recovery as evidence against feedback, check reachability, stability, saturation and leakage.

8Chemotaxis: random twofold variation and chosen protein titrations kept the precision and moved the level

Barkai and Leibler varied a model's parameters, and Alon and colleagues titrated chosen proteins. Both found the precision of adaptation robust and the steady level and adaptation time not. That pattern does not by itself place the memory. The models derive an error-integrating memory, and one mutant and one deletion support parts of that mechanism.

Four objects carry the name "chemotaxis" and stay apart here. The pathway is the biology: attractant binds the receptor, the receptor-coupled kinase CheA phosphorylates the response regulator CheY that makes the motor tumble, CheR and CheB add and remove methyl groups, and CheA also phosphorylates CheB. The steady activity is not robust either: it "depends on the enzyme concentrations" (p. 916). The sample is finite and twofold. It is not every parameter value.

The mechanism they proposed is an error-reading memory, and they state its robustness class themselves. Robust adaptation follows "when the rates of the modification and the reverse-modification reactions depend solely on the system activity, A, and not explicitly on the concentrations Em and E", and they read this as "a feed-back system, in which the output A determines the rates of modification reactions" (pp. 915–916). They "systematically varied the concentrations of the chemotaxis-network proteins" (p. 169) and stimulated cells with 1 mM L-aspartate.2 Precision is "the ratio between the steady-state tumbling frequency of unstimulated and stimulated cells" (p. 169), measured within one strain. That combination alone does not identify the memory. Precision compares a strain with itself, so it measures the input dependence ε\varepsilon for the one tested step, and never the set-point shift Δ\Delta between strains. CheR and CheB set the reference, as AstA_{\mathrm{st}} shows, and Figure 2's reference column leaves the error integrators and the incoherent feedforward loop alike input invariant with a moved set point. The paper asked a different question, "To differentiate between the fine-tuned and robust scenarios" (p. 169), and answered it.

Three other pieces of evidence support an error-integrating memory in chemotaxis: the models derive it, and two experiments support parts of the mechanism. It separates that phosphorylation feedback from demethylation that depends on the active conformation, and is consistent with the latter. The third is the deletion: a strain without CheR "did not tumble and could not adapt" (p. 169). That shows the memory's writer is needed. Sort a paper's perturbations by what they can discriminate. A change of the plant upstream of the integrated variable can separate a memory identity free of plant rate laws from one that contains the output's removal law. A titration of a reference constant, or a change downstream of the integrated variable, cannot.

9Searches over network designs fixed the input class, so both routes qualified

The searches that sorted adaptive networks into feedback and feedforward classes defined robustness against one input at one node. Under that class both routes adapt, exactly as the thesis predicts.

Ma and colleagues defined robustness as a count of sampled parameter sets that adapt to one input step. They stepped the input at node A from 0.5 to 0.6, asked for a sensitivity above 1 and a precision above 10, and judged "a circuit ... to be more robust if a larger number of parameter sets yield the behavior defined above" (p. 762), from 10,000 parameter sets sampled log-uniformly per network (p. 772).3 Of 16,038 three-node networks, 395 adapted robustly, and all contain a negative feedback loop with a buffering node or an incoherent feedforward loop with a proportioner node. In the feedforward class, node B "monitors the input and exerts an opposing force on node C" (p. 766). The robustness class was sampled parameters under an input step, and under it both memories qualify.

Araujo and Liotta asked for adaptation without fine-tuned parameters in a network of fixed topology, still for a stimulus at one input node. Their output node must return "regardless of the magnitude of the stimulus delivered to the input node, with no requirement for special (fine-tuned) parameter choices" (p. 11), while the set point is allowed to depend on the parameters (SI p. 4).4 Every such network decomposes into opposer modules, which compute "an integral of a tracking error", and balancer modules, of which Ma and colleagues' proportioners are special cases (pp. 4, 6, 10). These topological conditions are necessary, and the authors note that they "are not sufficient by themselves to guarantee the implementation of RPA across all possible parameter regimes" (p. 12). Their framework already contains the load test. When the stimulus enters at the output node itself, balancing is impossible and only opposition remains (Corollary 2, SI p. 13).

Later work named the input-node assumption as a choice. Gupta and Khammash note that earlier quantitative studies let disturbances enter "via a prespecified input node", and that biological disturbances "do not have a single well-defined entry point" (p. 1).10 Xiao and Doyle draw the design consequence. A controller built from species outside an unknown plant "always gives rise to a feedback system", while an incoherent feedforward loop "can only be obtained by a design problem where we are given how the disturbance enters the target variable" (p. 7).13 Jeynes-Smith and Araujo, searching the two-node reduction of Ma and colleagues' feedback design with every complex, add the first named thing: the quantity that adapts is the pool A∗+C3A^*+C_3, within ±1% and over a limited input range, not the free output (pp. 4–5).8

Read a design search's definition of robustness before reading its classes: say where its disturbance enters, which changes it samples, and whether its set point may move. A search whose disturbance enters only at an input node cannot separate the feedforward class from the feedback class.

10Synthetic integral controllers: the protease was the downstream test

The antithetic controller's theory claims the largest robustness class short of its own reference constants, and its experimental test applied a change downstream of the input. Growth dilution changes the identity. Transient speed and noise require separate performance tests.

Briat, Gupta and Khammash claim tracking against every network parameter except the two that set the reference. In their stochastic setting, if the closed loop is ergodic, the controller imposes tracking "regardless of the initial conditions or model parameters (other than μ/θ). A sudden change in these parameters will result in the same steady-state value after a transient" (p. 20).15 Their worked example claims adaptation "with respect to any change in the parameters of the gene expression network" (p. 22), and their theorem needs an open loop that is already stable, "because our controller can only act positively on the open-loop network" (p. 21). The claim is about the mean of the regulated species. Their Theorem 1 assumes a closed loop that "is ergodic and has uniformly bounded first- and second-order moments" (p. 20), and their controller is the annihilation reaction, in which one molecule of each controller species removes the other. A pair that binds reversibly, as in the core's Model 4, keeps the same difference identity but is not covered by the theorem as stated (core A4).

Aoki and colleagues tested a changed removal rate of the regulated protein, the downstream class. In their circuit the sigma factor SigW drives both AraC, which closes the loop by regulating the anti-sigma factor RsiW, and a coexpressed reporter, sfGFP. An induced protease, MfLon, "recognizes cognate Pdt degradation tags appended to the C termini of AraC and sfGFP and increases protein degradation" (p. 536).5 The perturbation therefore loads the sensed output, not only the reporter.

The measured class agrees with the inferred memory, approximately and within the tested conditions. The memory is the difference of the two controller species, the identity (7), which contains no rate law of the plant and so predicts that an added protease is rejected. The authors name what keeps the agreement approximate. Their theory assumed unsaturated production and "negligible degradation of controller proteins Z1 and Z2. Dilution is the change that the antithetic memory does not tolerate exactly. Qian and Del Vecchio show that dilution makes an integral memory leak, so that "the adaptation error can be arbitrarily large" (p. 4), and prove that the error becomes negligible "if the reactions implementing the integral controller are all much faster than dilution" (p. 1).16 Olsman, Xiao and Doyle find the trade from the other side: controller degradation "decreases the fragility of the system at the cost of introducing steady-state error" (p. 283), and that error is parameter dependent enough that it "may undermine the whole purpose of the circuit" (p. 284).17 Section 6 gave the core's number: a 9.8% shortfall at λ=0.1\lambda = 0.1.

Separate the classes a synthetic controller meets from those it does not. The antithetic pair tolerates an input, a plant change and a load, given a feasible and stable rest. It meets dilution only approximately, as the controller's turnover outpaces growth, and an exact steady state says nothing about its transient performance.

11Input scale and Ras: classes that do not place a memory

Fold-change detection is invariance of a whole response to the scale of the input, a property of the input class. The Ras experiments tested input level only. Neither class separates a memory identity that contains the output's removal law from one that does not.

Fold-change detection asks more than adaptation, and it is a property of the input class. Goentoro and colleagues defined it as a response for which a step from level 1 to 2 "provides exactly the same output" as a step from 2 to 4 (p. 894), and showed that an incoherent feedforward loop has it because "the repressor Y acts as a memory of the activator X" (p. 896).18 They also note that "Not all circuits with precise adaptation, however, are expected to show fold-change detection" (p. 897). Shoval and colleagues showed that fold-change detection entails exact adaptation, and that a stable, exactly adapting system has it when its equations are unchanged by scaling the input and an internal variable together (pp. 15995, 15997).19

Both feedforward and feedback memories can carry fold-change detection, but neither the core's incoherent feedforward loop, a sniffer, nor its linear integral loop has it. Shoval and colleagues find that the sniffer, in which the memory speeds the output's removal, "does not show FCD", and that integral feedback "does not provide FCD in its commonly used linear form" (pp. 15997–15998). The feedback design that has it is a nonlinear pair, with memory xx, output yy and input uu: x˙=x (y−y0)\dot x = x\,(y - y_0) with y˙=u/x−y\dot y = u/x - y (their eqs. 11 and 12, p. 15998). Its memory equation "multiplies the error y−y0y - y_0 by xx" and its output equation "uses a ratio-based controller u/xu/x", one for each of their two scaling conditions (p. 15998), so the pair supplies the symmetry, not the multiplicative memory alone. That memory also integrates the error in its logarithm, which is the multiplicative route of the core (core §4). Input scale is one more class that does not separate the two routes.

The Ras experiments tested the input class, and the model selection rested on the transients. Takeda and colleagues stepped cAMP over concentrations "ranging from 1.0 × 10−2 to 1.0 × 103 nM", and the reporter returned to its prestimulus level within 35 s at every concentration.6 The reporter is cytosolic RBD-GFP, whose intensity falls when it binds Ras-GTP at the membrane. They fitted a feedforward model and an integral-feedback model to the same data, "21 data points" for "nine free model parameters", and rejected the feedback model because its "adaptation kinetics" depended strongly "on the size of the stimulus step". Latrunculin B removed actin-dependent feedback and left adaptation intact. They also allowed that "adaptation is achieved downstream from the receptors and upstream from RasGEF".

Read through the three names, the inference is a model selection among two candidates, and a downstream change would test it. Steps of input level are the class to which both fitted models adapt exactly, so adaptation itself could not decide, and the decision came from the shape of the transients within the two fitted models. Latrunculin B removes one feedback route, but it neither loads activated Ras nor changes its removal. The thesis proposes the change that would test those two fitted mechanisms: a first-order load on Ras-GTP, removing it independently of the input. In the fitted feedforward model, whose error-integrating coordinate contains activated Ras's own removal through RasGAP, such a load would move the set point. In the fitted integral-feedback model it would not. This is a proposed test of the two fitted mechanisms, not a decisive test of every possible topology. Whether the reporter itself, which binds Ras-GTP, acts as such a load is the question of the Lecture 10 worked extension.

Name the change that would test a published feedforward inference: a first-order load or an input-independent change of the output's removal, applied with the input held at several levels. Do not read input-level invariance, or fold-change detection, as evidence for either route.

Part V

Choosing the change

Which change tells candidate memories apart, whether the evidence read here meets either refutation criterion, and what remains open.

12Choose a perturbation with different model predictions

Among candidate mechanisms, the change an experiment applies separates a memory identity that contains the output's removal law from one that does not. The strongest comparison is a specified load with the reference held fixed. Its outcome can reject a candidate model only after checking that the model could still reach its set point.

Among the candidates, and within the cited theorems' settings, nothing rejects a first-order load without an identity free of plant rate laws, so the first criterion is not met. Among the core's designs, the two that tolerate the load, the integral loop and the sequestering pair, both have one, equations (3) and (7). The theorems of Section 7 exclude the alternative in their own settings. Absolute concentration robustness, the other structural robustness known for reaction networks, concerns a different class: one species takes the same value "in every positive steady state the system might admit", whatever the conserved totals (Shinar and Feinberg, p. 1389).20 As Xiao and Doyle note, perfect adaptation in general "could reject disturbances other than the total concentration" (p. 5).13 A network outside the candidates and the theorems' settings is not covered by the claim, so it could not refute it either.

No measured response read here contradicts a named fitted model with its conditions checked, so the literature criterion is not met either. In chemotaxis the titrations could not discriminate and agree with the inferred error-reading memory, and the truncated-CheB result agrees with activity-dependent demethylation (Section 8). In the synthetic controller the protease test is the downstream class, and the closed loop rejected it as the antithetic identity predicts, approximately and within a roughly threefold output range (Section 10). The Ras inference has not met the proposed test: its robustness class was the input level, which both fitted models pass (Section 11).

Four questions remain open in this analysis, and each names the change or the hypothesis it needs. The first is the proposed load test of the two fitted Ras mechanisms in Dictyostelium, with the reporter's own binding to activated Ras accounted for. The second is a measurement of the set-point shift Δ\Delta, not only of the input dependence ε\varepsilon, under a change of the receptor alone, a plant change upstream of the variable that methylation integrates. Alon and colleagues changed receptors only together with CheR, CheB, CheY and CheZ. The third is how the robustness class extends to disturbances that vary in time, where exact adaptation to a constant input says nothing about the transient. The fourth is a criterion for networks with conservation laws: this essay has not applied one to the core's two-cycle feedback circuit, which Gupta and Khammash's full-rank hypothesis, as stated, does not cover.

Reaction orders and perturbation tests answer successive questions. Binding allocations determine which effective laws a mechanism can realize. A perturbation test then asks which of those laws continues to restore the specified output. Lecture 11 develops the first calculation. The comparison here supplies the second.

The conclusion depends on the observable, disturbance class and robustness class. A claim of robust perfect adaptation is a claim about an observable, a class of disturbances and a robustness class. The first two can be met by a memory identity that contains the plant's own removal law, as the incoherent feedforward loop's coordinate's does, or by one that does not. The third, when it contains a first-order load or a changed removal rate of the output, is met among the candidates only by a memory whose identity contains no rate law of the plant, and beyond them only where a theorem's hypotheses hold. That is why the change an experiment applies, more than the adaptation it observes, tells candidate memories apart.

Design the discriminating experiment for a new adaptive system: choose a change from Table 2 that splits the candidate memories, apply it with the input held at several levels, measure the set-point shift as well as the input dependence, and check reachability, stability, saturation and leakage before reading a failure. State what the result cannot conclude: the molecule that carries the memory and the network's topology.
