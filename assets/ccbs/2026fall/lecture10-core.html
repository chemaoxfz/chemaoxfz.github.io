The adaptation biomachine

Choose a function. Follow its implementation from a controller to molecules. Binding and catalysis supply the reaction orders that make adaptation possible, and the dominance regimes that limit its range.

CCBS · EST 5053 · Fall 2026 · Lecture 10 · core · 13 October 2026 · 10:40–12:15

Lecture 9 gave us a vocabulary for diverse biological behaviors. A graded response, a switch, feedback regulation and adaptation all arose from binding and catalysis. The behavior changed as different species came to dominate the totals. A dominance regime says which molecular form carries each total. Transitions between those regimes explain why one mechanism can behave in several ways.

We now use those components to ask what a cell accomplishes. Instead of beginning with a pathway and listing its reactions, choose a function and ask how the pathway achieves it. Today the function is adaptation: an output responds to a persistent change, then returns.

The classroom route has eleven points. The prelude chooses the function. Part 1 builds a controller visually. Part 2 implements it with molecules. Part 3 asks why a feedforward circuit can also adapt. The 95-minute rundown gives the timing. The optional readings retain the theorem, detailed calculations and alternative experiments. Prelude

Choose the function before analyzing the machine

1A function gives physical components an architecture

A computer becomes easier to understand when we name the jobs its components perform. The same method helps us understand a cell.

Functional descriptions organize an engineered machine. We describe a computer through its processor, memory, input devices, operating system and applications. These terms identify roles and relations. A description of every atom and electrical interaction would obey physics, but would bury the explanation of what the computer does. A clock or an aircraft also becomes intelligible through the function and architecture of the whole machine.

A biomachine perspective begins by choosing the function we want to explain. Specify an input the cell encounters, an output we measure, and the behavior the output should achieve. Then identify which binding and catalysis reactions sense, store, transform and act. The functional roles are conceptual. The components that realize them are physical. Choosing a function makes an explanatory claim that we can test against the cell's behavior.

1A function tells us which input, output and internal roles matter.

The coming lectures choose several functions for the same biochemical components. We will study computation, metabolism and growth as biomachine perspectives. The final mini-essays can develop other functions. Here we choose the adaptation biomachine because its function is easy to observe and its mechanisms expose the role of dominance regimes.

Lagrangian mechanics can eliminate explicit constraint forces by choosing generalized coordinates. This also shows how a useful representation can hide distracting internal detail. Lagrangian mechanics remains a description of dynamics. It is not itself a functional specification or inherently an input-output theory.

Part 1

What must an adaptation controller do?

A persistent disturbance needs a persistent corrective action. The output can return only if that action remains after the visible error disappears.

2Adaptation restores the output while the disturbance stays

Imagine keeping a platform at a chosen height while a new load keeps pushing it down. Returning to the original height requires the actuator to retain a new force.

The adaptation experiment separates a transient response from a lasting error. Hold an input until the system settles, change it, and hold the new value. Measure the output's displacement and its final value. Perfect adaptation means the output returns to the same steady value across the stated input range. Near-perfect adaptation needs a tolerance. A 5% tolerance, for example, permits a final relative error no larger than 5%.

2The disturbance stays. The output returns. The corrective action changes.

Robustness names the changes that preserve this behavior. An output may be independent of the input while its return value depends on enzyme abundance or other parameters. Holding the same reference under a parameter change is a stronger requirement. We will specify which claim each example makes.

Lecture 9's high-gain feedback reduces the error but usually leaves an offset. A small error still has to sustain the compensating action. The next construction stores that action in another state, so the output no longer has to carry it.

Read an adaptation experiment by comparing the final input, output and corrective action.

3Integral action removes the offset when the loop settles

Proportional control reacts to the present error. Integral control remembers accumulated error. A stable combination can both restore the output and retain the required action.

A simple plant makes the difference visible. Let y be the signed deviation of the output from its target, w a constant disturbance, and u a corrective action that opposes w. Choose normalized units so the plant obeys y˙=w−u\dot y=w-u. This is an illustrative control model. It says that an unbalanced drive changes the output.

Proportional control needs a nonzero error to maintain a nonzero action. With u=kPyu=k_Py and positive gain kPk_P, a rest requires y∗=w/kPy^*=w/k_P. Increasing the gain reduces the offset. At zero error this controller produces zero action, so it cannot balance a nonzero disturbance.

Integral control keeps changing the action until the error vanishes. Introduce a memory z with z˙=y\dot z=y and use u=kIzu=k_Iz, where kI>0k_I>0. At a rest, z˙=0\dot z=0 forces y∗=0y^*=0, while z∗=w/kIz^*=w/k_I retains the needed action. The controller remembers the past error after the current error disappears.

3An integral can rest only at zero error. Its stored value supplies the persistent action.

The equilibrium condition does not make the trajectory converge. For integral control alone, differentiating the plant equation after the disturbance becomes constant gives y¨+kIy=0\ddot y+k_Iy=0. The output oscillates. Proportional plus integral control, u=kPy+kIzu=k_Py+k_Iz, adds damping:

y¨+kPy˙+kIy=0.\ddot y+k_P\dot y+k_Iy=0.

For positive gains both characteristic roots have negative real parts. This particular loop therefore settles at zero error. In a more complicated plant, stability needs a new check.

4Integral action fixes the possible rest. Stability determines whether the output reaches it.

The PID vocabulary

A proportional-integral-derivative controller combines present error, accumulated error and the rate of change of error: u=kPy+kI∫0ty(s) ds+kDy˙u=k_Py+k_I\int_0^t y(s)\,ds+k_D\dot y, with an initial memory value added when needed. Integral action supplies the zero-error equilibrium condition. Proportional and derivative actions can shape the transient response. The gains must still suit the plant. We need only proportional and integral actions in the example above.

For a proposed controller, first find the equation that forces zero error at rest. Then check that the rest is reachable and stable. The internal model theorem makes a necessity statement under additional hypotheses.

Part 2

How can binding and catalysis implement that controller?

A molecular concentration cannot fall below zero. Begin with reactions that respect this constraint, then ask which dominance regime gives the desired controller equation.

4A saturated enzyme removes the memory at an almost constant rate

The first chemical construction uses a flux that becomes nearly independent of the amount being removed. That independence must be derived from the enzyme complex.

Resolve the memory's production and destruction before simplifying them. The measured output X drives production of a memory species Z at rate θX\theta X. An enzyme E binds Z and catalytically converts it to an inert product P. The enzyme total qE=E+CEZq_E=E+C_{EZ} is fixed. With association, dissociation and catalytic constants k+k_+, k−k_- and kcatk_\mathrm{cat}, the full ODEs are

Z˙=θX−k+EZ+k−CEZ,E˙=−k+EZ+(k−+kcat)CEZ,C˙EZ=k+EZ−(k−+kcat)CEZ,P˙=kcatCEZ.\begin{aligned}\dot Z&=\theta X-k_+EZ+k_-C_{EZ},\\\dot E&=-k_+EZ+(k_-+k_\mathrm{cat})C_{EZ},\\\dot C_{EZ}&=k_+EZ-(k_-+k_\mathrm{cat})C_{EZ},\\\dot P&=k_\mathrm{cat}C_{EZ}.\end{aligned}

Adding the free and bound memory balances gives an exact equation. Define the memory total qZ=Z+CEZq_Z=Z+C_{EZ}. Binding and unbinding merely redistribute this total, so

q˙Z=θX−kcatCEZ.\dot q_Z=\theta X-k_\mathrm{cat}C_{EZ}.

Enzyme saturation makes the removal nearly zero order in the memory. Suppose reversible binding equilibrates much faster than production and catalysis. With Kd=k−/k+K_d=k_-/k_+, the fast-binding relation is CEZ=qEZ/(Kd+Z)C_{EZ}=q_EZ/(K_d+Z). In the dominance regime Z≫KdZ\gg K_d, the complex carries almost all of qEq_E. Therefore

q˙Z≈θX−kcatqE=θ(X−X∗),X∗=kcatqEθ.\dot q_Z\approx\theta X-k_\mathrm{cat}q_E=\theta(X-X^*),\qquad X^*=\frac{k_\mathrm{cat}q_E}{\theta}.

The memory total now integrates the output error approximately. To close negative feedback, increasing the memory must reduce X. This sign is part of the design.

5The exact removal is kcatCEZk_\mathrm{cat}C_{EZ}. It becomes nearly constant only when the complex dominates the enzyme total.

The saturation error gives a quantitative operating condition. The fractional deficit from maximal removal is Kd/(Kd+Z)K_d/(K_d+Z). It is at most 5% when Z≥19KdZ\ge19K_d. As Z is depleted, the deficit grows and the integral approximation fails. At Z=0Z=0, removal vanishes, as chemical feasibility requires.

When the Michaelis constant replaces the dissociation constant

If complexes instead relax by binding, unbinding and turnover together, an appropriate quasi-steady-state approximation uses KM=(k−+kcat)/k+K_M=(k_-+k_\mathrm{cat})/k_+. The saturation condition is then Z≫KMZ\gg K_M. At a resolved steady state this complex relation is exact. A timescale argument is still needed to use it throughout a transient.

5Receptor methylation compensates a persistent attractant within a finite range

Bacterial chemotaxis uses the same principle: a modification balance can become independent of the stored modification. The biological pathway has more requirements than a single saturated enzyme.

Attractant and methylation push receptor activity in opposite directions. In Escherichia coli, attractant reduces receptor-coupled CheA kinase activity. Less CheY is phosphorylated, and the motor tumbles less. CheR adds methyl groups to receptors, which raises activity. CheB removes methyl groups. Receptor methylation therefore lets the pathway compensate for a persistent attractant.

The full modification balance counts catalytic events. Let qmethylq_\mathrm{methyl} be the concentration of receptor-bound methyl groups, qTq_T the fixed receptor concentration, and m=qmethyl/qTm=q_\mathrm{methyl}/q_T the mean methylation per receptor. Index catalytic receptor-enzyme complexes by j. Methylating complexes CR,jC_{R,j} add one group per event at rates kR,jCR,jk_{R,j}C_{R,j}. Demethylating complexes CB,jC_{B,j} remove one at rates kB,jCB,jk_{B,j}C_{B,j}. Then

m˙=1qT(∑jkR,jCR,j−∑jkB,jCB,j).\dot m=\frac{1}{q_T}\left(\sum_j k_{R,j}C_{R,j}-\sum_j k_{B,j}C_{B,j}\right).

An activity-only rate law needs specific biochemical assumptions. In the Barkai–Leibler reduction, bound CheR is approximately constant, CheB acts on active receptors, and the relevant catalytic ratios and binding constants do not depend on ligand occupancy or the stored modification. Yi and colleagues state the needed conditions explicitly. Saturation helps by making the methylating flux nearly constant. Saturation alone is insufficient.7, 6

The reduced teaching model then makes the adaptation calculation short. Let a be receptor activity as a fraction, VRV_R the constant methylating rate, VBV_B the maximal demethylating rate and KBK_B its half-rate activity. These rates are measured in methyl groups per receptor per time. The model is

m˙=VR−VBaKB+a,a∗=KBVRVB−VR.\dot m=V_R-V_B\frac{a}{K_B+a},\qquad a^*=\frac{K_BV_R}{V_B-V_R}.

The final expression follows by setting the first to zero. It contains no attractant level. A feasible activity needs VB>(1+KB)VRV_B>(1+K_B)V_R, and the receptors must be able to reach that activity using their available methylation sites. Changing an enzyme abundance can change the return value while preserving input invariance.

Do the molecular numbers support the regime?

Measured abundances support treating CheR and CheB as scarce enzymes. Li and Hazelbauer measured about 120±30120\pm30 receptor monomers per CheR and 80±1580\pm15 per CheB across two strains and two growth media. Their representative cell has about 20,000 receptor monomers, 180 CheR and 280 CheB molecules. These are measured ratios and a representative count inferred from them.21

Saturation needs an affinity comparison as well. Using an illustrative cell volume of 1 fL converts those counts to about 33 μM33\,\mu\mathrm M receptor monomers, 0.30 μM0.30\,\mu\mathrm M CheR and 0.46 μM0.46\,\mu\mathrm M CheB. If all 33 μM supplied accessible equivalent binding sites, 95% occupancy would require an effective binding constant below 33/19≈1.7 μM33/19\approx1.7\,\mu\mathrm M. This is a threshold calculation, not a measurement of that constant.

Measured affinities distinguish recruitment from catalytic saturation. Lai and colleagues report a CheR–receptor tether dissociation constant near 2 μM, while CheR binding to substrate sites is at least 50–100 times weaker. With the estimated 33 μM accessible tether concentration, a simple binding calculation gives 33/(33+2)≈0.9433/(33+2)\approx0.94 tether occupancy. This supports strong recruitment. It does not establish saturation of the catalytic site. Tethering changes local encounter rates, and available modification sites change during adaptation. Thus the abundance and affinity scales make the mechanism plausible but do not verify every assumption of the activity-only law.22

Finite methylation sites make the failure concrete. More attractant requires more compensating methylation. Once the required m exceeds the available sites, the activity cannot return. 6Opposing saturated modification fluxes create ultrasensitivity

Before closing feedback, build the high-gain module. A phosphorylation-dephosphorylation cycle becomes ultrasensitive when both enzymes are saturated by their substrates.

Resolve both directions of the modification cycle. E converts unmodified S to modified S∗S^*, while F converts it back. The equations below resolve substrate binding and modification. They assume the required chemical fuel and products are held at fixed conditions.

E+S⇌kE−kE+CES→kEE+S∗,F+S∗⇌kF−kF+CFS∗→kFF+S.\begin{aligned}E+S&\xrightleftharpoons[k_{E-}]{k_{E+}}C_{ES}\xrightarrow{k_E}E+S^*,\\F+S^*&\xrightleftharpoons[k_{F-}]{k_{F+}}C_{FS^*}\xrightarrow{k_F}F+S.\end{aligned}

The exact modified-pool balance is the difference of the catalytic fluxes. Define qS∗=S∗+CFS∗q_{S^*}=S^*+C_{FS^*}, enzyme totals qE=E+CESq_E=E+C_{ES} and qF=F+CFS∗q_F=F+C_{FS^*}, and substrate inventory S0=S+S∗+CES+CFS∗S_0=S+S^*+C_{ES}+C_{FS^*}. Then q˙S∗=kECES−kFCFS∗\dot q_{S^*}=k_EC_{ES}-k_FC_{FS^*}.

Fast binding gives two saturating fluxes. Let KE=kE−/kE+K_E=k_{E-}/k_{E+} and KF=kF−/kF+K_F=k_{F-}/k_{F+}. The enzyme-trace approximation additionally assumes qE,qF≪S0q_E,q_F\ll S_0, so free substrate approximately accounts for the substrate inventory. The reduced balance is

q˙S∗≈kEqESKE+S−kFqFS∗KF+S∗.\dot q_{S^*}\approx k_Eq_E\frac{S}{K_E+S}-k_Fq_F\frac{S^*}{K_F+S^*}.

When both enzymes saturate, their capacities nearly decide the direction of motion. Inside S≫KES\gg K_E and S∗≫KFS^*\gg K_F, the balance approaches kEqE−kFqFk_Eq_E-k_Fq_F. A small excess in one capacity keeps moving the modification fraction until one substrate leaves saturation. The steady fraction therefore changes sharply near equal opposing capacities. This is zero-order ultrasensitivity.8

7Two nearly constant opposing fluxes turn a small capacity imbalance into a large change in modification.

Feedback can turn this high gain into adaptation. Instead of fixing both enzyme activities externally, let the output of one cycle regulate the other. Then the difference of the opposing fluxes can become an output-error signal. We now make that construction with two coupled cycles.

7One joint dominance regime exposes the two-cycle integral

Modified A promotes the modification of B. Modified B removes the modification from A. This closes negative feedback around the modification machinery. We will calculate in one sufficient regime.

Define qA=A+C1q_A=A+C_1, qA∗=A∗+C2+C3q_{A^*}=A^*+C_2+C_3, qB=B+C3q_B=B+C_3, qB∗=B∗+C2+C4q_{B^*}=B^*+C_2+C_4, qI=I+C1q_I=I+C_1 and qE=E+C4q_E=E+C_4. 8One-to-one sequestration gives an exact difference integral

Saturation gave an approximate integral over a range. Stoichiometry offers another construction: two nonnegative species can have a signed difference.

Produce two controllers and remove them in pairs. A reference produces Z1Z_1 at rate μ. The output X produces Z2Z_2 at rate θX\theta X. The two bind reversibly and their complex is removed. Define each controller total as its free concentration plus the complex concentration. Binding, unbinding and pair removal change the totals equally, so subtraction gives

ddt(qZ1−qZ2)=μ−θX.\frac{d}{dt}(q_{Z_1}-q_{Z_2})=\mu-\theta X.

The difference identity is exact at every binding allocation. Any steady state satisfies X∗=μ/θX^*=\mu/\theta. The actuator Z1Z_1 can rise to supply more output after a removal disturbance, while X returns to the reference. Aoki and colleagues implemented this architecture using the sigma factor SigW and its anti-sigma factor RsiW.15

9Pair removal cancels exactly from the difference of the controller totals.

Dilution adds a leak to that difference. If all controller forms dilute at rate λ, the difference obeys z˙=μ−θX−λz\dot z=\mu-\theta X-\lambda z, where z=qZ1−qZ2=Z1−Z2z=q_{Z_1}-q_{Z_2}=Z_1-Z_2. At rest the signed relative error is (X∗−μ/θ)/(μ/θ)=−λz∗/μ(X^*-\mu/\theta)/(\mu/\theta)=-\lambda z^*/\mu. Near-perfect adaptation therefore requires the magnitude of this leak to be small compared with μ.

An exact difference equation still needs a feasible, stable plant response. If the actuator cannot reach the required output, the memory keeps accumulating. If the plant has a sufficient lag, the closed loop can oscillate instead of settling. Part 3

Why can a feedforward circuit also adapt?

The input can create both an output and its remover. Their opposing effects can cancel without an output-to-controller feedback edge. The binding regime decides which rate law makes that possible.

9Bilinear catalytic removal lets the input cancel at steady state

An incoherent feedforward loop sends one input through two branches with opposing effects. Begin with the chemistry of the opposing branch, rather than assuming its rate law.

Resolve the binding between output and degrader. Input w drives production of output X1X_1 at rate k1wk_1w and degrader X2X_2 at rate k2wk_2w. Their complex converts the output to an inert product P while returning the degrader:

X1+X2⇌k−k+C12→kcatX2+P.X_1+X_2\xrightleftharpoons[k_-]{k_+}C_{12}\xrightarrow{k_\mathrm{cat}}X_2+P.

Specify degrader turnover so the total balances are unambiguous. Let q1=X1+C12q_1=X_1+C_{12} and q2=X2+C12q_2=X_2+C_{12}. The degrader is removed at frequency γ whether free or bound. Removing a bound degrader releases its intact output. Production and removal are composite processes. The full resolved model is

X˙1=k1w−k+X1X2+(k−+γ)C12,X˙2=k2w−γX2−k+X1X2+(k−+kcat)C12,C˙12=k+X1X2−(k−+kcat+γ)C12.\begin{aligned}\dot X_1&=k_1w-k_+X_1X_2+(k_-+\gamma)C_{12},\\\dot X_2&=k_2w-\gamma X_2-k_+X_1X_2+(k_-+k_\mathrm{cat})C_{12},\\\dot C_{12}&=k_+X_1X_2-(k_-+k_\mathrm{cat}+\gamma)C_{12}.\end{aligned}

Adding the balances gives the exact total equations q˙1=k1w−kcatC12\dot q_1=k_1w-k_\mathrm{cat}C_{12} and q˙2=k2w−γq2\dot q_2=k_2w-\gamma q_2. No bilinear removal in totals has been assumed.

Fast binding and mostly free totals produce the bilinear law. With Kd=k−/k+K_d=k_-/k_+, rapid reversible binding gives X1X2=KdC12X_1X_2=K_dC_{12}. If q1,q2≪Kdq_1,q_2\ll K_d, each total is carried mainly by its free species. Then C12≈q1q2/KdC_{12}\approx q_1q_2/K_d. Write the resulting reduced totals as x1,x2x_1,x_2, and define δ=kcat/Kd\delta=k_\mathrm{cat}/K_d:

x˙1=k1w−δx1x2,x˙2=k2w−γx2.\dot x_1=k_1w-\delta x_1x_2,\qquad \dot x_2=k_2w-\gamma x_2.

The same input factor appears in production and removal at steady state. For constant w>0w>0, the reduced degrader rests at x2∗=k2w/γx_2^*=k_2w/\gamma. Substitution into the output balance gives

x1∗=k1wδx2∗=k1γδk2.x_1^*=\frac{k_1w}{\delta x_2^*}=\frac{k_1\gamma}{\delta k_2}.

A1Sontag's theorem needs no plant-controller split

A10 stated the classical principle, which assumes a controller that sees only the error and a regulation that survives small changes of the plant. Sontag's 2003 theorem reaches an internal model from adaptation itself, under different hypotheses.

Sontag assumes adaptation and signal detection, not a split or robustness. His note shows that if a system adapts to a class of external signals, in the sense of regulation against disturbances, then it must contain a subsystem that can generate all those signals. It does not assume that the regulation is robust, nor that the system is split into plant and controller. It assumes instead a signal-detection property, together with bounded trajectories.3

Signal detection is a condition on how the output sees the input. Sontag's precise condition is a uniform relative degree: a specified derivative of the output depends nontrivially on the instantaneous input. The signals are generated by a Poisson-stable exosystem, and the global result also assumes completeness and commutation of certain normalized vector fields. Theorem 1 is on p. 124, the definition of an output-driven internal model is on p. 122, eqs. (E3) and (E4), and Remark 3.2 on p. 125 qualifies the global result.3

A3Moving the actuation to the sensor changes the noise, not the mean

A6Fold-change detection is a different adaptive property

Some feedforward loops have a second property beside returning to a steady output. It is a different property, and it is not the subject of this lecture.

Fold-change detection is a different adaptive property, which some incoherent feedforward loops have. Separate the return of a steady output from fold-change detection before attributing either to an incoherent feedforward loop.

A8Why an adaptive state model needs another changing state

An input steps up and stays up, and the output returns exactly to its old value. Where did the input go? One line of bookkeeping answers it for a stated kind of system: some other state has changed, and it holds the input. In Lecture 9's high-gain loop the only slow state is the output, so the output itself holds the input, as an error.

The questionA step in, a pulse out

Perfect adaptation is a transient response followed by return to the same steady output. Hold an input until the system rests, step it to a new value, and hold it there. The output can rise or fall before returning. Figure 16 shows a rise. Chemotaxis in A12 will show a fall. A nonzero final offset is the adaptation error. We call adaptation near-perfect only after stating a tolerance.

Two different robustness questions

Input invariance keeps the steady output independent of the input at fixed parameters. A parameter change may preserve input invariance while moving the value to which the output returns.

A fixed set point survives a specified change of the system. State which parameters change and which reference parameters stay fixed. Chemotaxis in A12 separates these two questions. The load comparison in A16 turns the distinction into an experiment.

The bookkeepingSome other state must change

One line of bookkeeping says where the input went, for a stated kind of system. Take a model s˙=f(s,u)\dot s=f(s,u), where s collects the model's states and u is its input. Suppose it rests at a finite steady state before the step, the input is then held at its new value, and the model settles to a finite steady state after it. Suppose also that the output is read from the state and responds to the step, so the step changes the vector field f at the old rest. Then the old rest is no longer a rest under the new input, and the new steady state differs from the old one. The output is the same at both, so the difference sits in some other state. That state holds the input, and we call it the memory.

The argument has a domain, and three cases lie outside it. It does not cover an output that feeds through the input directly, a pulse driven by the input's rate of change, or hidden variables that never settle. So it is not a theorem about every observed pulse. It is a statement about models that settle, with the output read from their state.

Lecture 9's loopThe output itself holds the input, as an error

In Lecture 9's high-gain loop the output itself holds the input. A repressor represses its own gene, and growth dilutes it. Promoter binding is fast, so the repressor total is the loop's only slow state, and it is the output. A change in production or removal moves the balance of the two, and a production curve of finite slope cannot rebalance at the same output (Figure 17). So the steady state must move, and the only state that can move is the output. It holds the input, as an error.

The size of that error is Black's factor. Write the repressed production as f(x)f(x), with x the output, and let the loop gain be H=−dln⁡f/dln⁡xH=-d\ln f/d\ln x at the set point. H is positive, because production falls as the output rises. In that model a small relative change in removal moves the set point by about 1/(1+H)1/(1+H) of it. That factor is a sensitivity to small changes. Figure 17 shows a finite, fourfold change, solved exactly, so its shifts are not given by the factor. The error is small when the loop gain is high, but never zero, because a finite slope always leaves the two crossings apart. Removing it needs a separate state that can hold the input while the output returns.

Find where a persistent input is held: in a model that settles, with the output read from its state and responding to the step, some other state must change. If the output is the only slow state, expect it to hold the input as an error, about 1/(1+H)1/(1+H) of a small relative change in a high-gain loop, and never zero.

A10State the hypotheses of an internal model theorem

Must a loop that robustly rejects a constant disturbance contain an integral? Under stated hypotheses, yes. Francis and Wonham's internal model principle requires a mode at zero frequency in the controller, an integral of the error, but not one molecule that integrates. Other theorems reach an internal model from other hypotheses, so an adapting trace alone does not prove that an integrator is present.

The theoremThe controller must copy what makes the disturbance

The internal model principle answers the question for linear systems, under stated hypotheses. Francis and Wonham posed the classical regulator problem for linear, time-invariant systems: a plant and a separate controller, with disturbances produced by a known signal generator, here constants. In classroom form there are four hypotheses. The controller sees only the error. The disturbances are constants. The closed loop is stable. And regulation must survive small changes of the plant's parameters. Under these hypotheses the controller must feed back the error and contain a copy of the system that generates the disturbances (p. 460, Figure 21).1

The four hypotheses paraphrase a linear theorem, not a theorem about every chemical network. Francis and Wonham extend the result to weakly nonlinear plants only locally, near an equilibrium, with constant signals (p. 462).1 A nonlinear chemical network that adapts may or may not meet these hypotheses, and each case must be checked.

For constant disturbances that copy is a mode at zero frequency, which acts as an integral of the error. A constant d is generated by w˙=0\dot w=0, with d=wd=w. A controller holding the same mode, driven by the error e, is z˙=e\dot z=e: the integral of A9. Integral feedback has infinite gain at zero frequency, which is why it removes a constant error exactly.2

The theorem asks for a mode, not a molecule. It does not require one physical species to integrate the error with a constant gain. The mode can live in a combination of states, which A16 will need.

Other theoremsHypotheses decide what a theorem proves

Other theorems reach an internal model from different hypotheses. Sontag's 2003 theorem assumes that the system adapts to a class of signals, together with a signal-detection condition and bounded trajectories. It assumes no split into plant and controller, and no robustness requirement.3 It concludes that the system contains a subsystem that can generate those signals. So the principle is a family of theorems that answer different questions (optional A1).

An adapting trace alone does not prove that an integrator is present. A trace shows the output returning. Each theorem also needs its hypotheses checked: what the controller sees, which disturbances act, which changes of the plant are allowed, and whether the loop is stable. A11Compare three chemical constructions of an integral

A capacitor can store a signed charge, so signed integration has a direct electrical implementation. A concentration cannot go below zero, and a species' removal must stop when the species is gone. So no single species is an exact integrator across the whole range. Three useful routes go around it, and each has its own limit.

The obstacleA capacitor holds a signed charge, and a concentration cannot

A capacitor can accumulate current of either sign. The charge Q on a capacitor is the integral of the current I through it, and the current can flow either way, so Q can be positive or negative (Figure 22, left). That is why the integrator of A9 is easy to build from electronics.

A concentration cannot go below zero, and a species' removal must stop when the species is absent. Suppose a species Z were the memory, with Z˙=μ−θX\dot Z=\mu-\theta X, where Z is its concentration, μ\mu a constant reference rate and θX\theta X a removal rate set by a sensed output X. The limitsWhat the identity does not guarantee

The identity does not guarantee three things, and the first two are reachability and exactness under dilution. The set point must be reachable. If the plant cannot make enough output, X stays below μ/θ\mu/\theta, the difference keeps growing, and a controller pool accumulates without bound: windup. The controllers must also not be diluted. Growth dilutes free and bound controllers alike, the complex cancels from the difference, and the free controllers leave a leak, −λ(Z1−Z2)-\lambda(Z_1-Z_2), on the right side of (E7). That leak in general breaks exactness. Adaptation is then near-perfect only when the leak is small enough, so growth by itself does not guarantee a small error.

The third guarantee that is missing is stability, and it depends on the plant. With the linear one-stage plant drawn here, reversible sequestration and no controller leak, the rest is locally stable for every choice of positive constants (the stability audit below gives the certificate). That is a property of this plant, not of every one-stage plant. With a two-stage plant, in which Z1Z_1 drives an mRNA that makes X, a high actuation gain can make the rest unstable. Instability is not yet an oscillation: a sustained cycle is shown by simulation, not inferred from an eigenvalue. Briat, Gupta and Khammash note that the deterministic controller oscillates in an instability region, where its stochastic counterpart still adapts in the mean (p. 24, optional A4).14

The mRNA stage adds a lag, and a loop with a lag can overcorrect. A change of the actuator now reaches X only after the mRNA has changed. Meanwhile the controllers keep integrating the error, so when X finally responds the actuator has already moved too far, and the output overshoots the other way. This argument shows only that instability is possible. Whether it occurs, and at which gains, needs the test, and here it is not monotone in gain: each unstable window below closes again at higher gain.

The two-stage results use the annihilation controller, the form Briat, Gupta and Khammash analyze. In it, one Z1Z_1 and one Z2Z_2 remove each other in a single composite step, Z1+Z2⇝∅Z_1+Z_2\rightsquigarrow\varnothing, with the rate law ηZ1Z2\eta Z_1Z_2, where η\eta is the annihilation rate constant: Z˙1=μ−ηZ1Z2\dot Z_1=\mu-\eta Z_1Z_2 and Z˙2=θX−ηZ1Z2\dot Z_2=\theta X-\eta Z_1Z_2. The two-stage plant adds an mRNA M, with M˙=kZ1−γMM\dot M=kZ_1-\gamma_MM and X˙=βM−γXX\dot X=\beta M-\gamma_XX.

The experimentSigW and RsiW in E. coli

The experiment

Aoki and colleagues built the pair in Escherichia coli from the Bacillus subtilis sigma factor SigW and its anti-sigma factor RsiW, which sequesters it (p. 535). After a protease was induced, the closed loop showed virtually no change in its fluorescent reporter, while the open loop lost more than 40% in most conditions tested (p. 536).15 Their theory assumes negligible degradation of the controller proteins, which living cells do not satisfy, and their simulations with realistic parameters give small errors (p. 535). In growing cells the adaptation is near-perfect, not exact.

Two refinements stay outside the clock. Moving the actuation from the reference species to the sensor species changes the noise, not the set point of the mean (optional A3). In a noisy network the pair still adapts in the mean (optional A4).

Use the sequestering pair's identity: the difference of the controller totals integrates the error exactly at every binding allocation, so any rest has X=μ/θX=\mu/\theta and the actuator holds the compensating action. Before trusting it, check three things separately: a reachable set point, a controller leak small enough for the error you can accept, and a stable rest for the actual plant.

A15Generalize the feedforward rate laws

Return to Lecture 9's incoherent feedforward loop, in its simplest form. The input makes the output and also its degrader, and the output settles at a level with no input in it, because the input went into the degrader, in proportion. No constant had to match. What must match are reaction orders, and Lecture 9's two implementations adapted where their effective orders nearly matched.

The circuitThe input makes the output and its degrader

The simplest version has three species. The input W makes the output X1X_1 at rate k1wk_1w and its degrader X2X_2 at rate k2wk_2w, where w is W's concentration. X2X_2 removes X1X_1, a process the model does not resolve, with the rate law δx1x2\delta x_1x_2, and X2X_2 is itself removed at rate γx2\gamma x_2 (Figure 29). Lower-case letters are concentrations:

The output settles at a level with no input in it. At rest x2∗=k2w/γx_2^*=k_2w/\gamma, and then

for every constant w>0w>0. Feedforward loops are common in transcription networks, but prevalence is not function: in E. coli most of them (85%) are coherent, not incoherent.16

The input went into the degrader, in proportion. The degrader's steady level k2w/γk_2w/\gamma is proportional to the input, and it holds the input while the output returns. The ordersWhat must match are reaction orders

No constant had to match, so A9's compensator failure does not apply. Change any of the four rate constants k1k_1, k2k_2, δ\delta and γ\gamma, and the output still returns to a level with no input in it. Only that level moves.

What must match are reaction orders. In this simplest example the input enters both production paths at the same order, the first. The degrader acts on the output at the order at which it is itself removed, also the first. For monomial rate laws the general condition is one product of orders (optional A5).

Adaptation fails when the orders stop matching. Saturate the degrader's removal, and x2x_2 no longer tracks the input in proportion. Add an input-independent leak k0k_0 to the output's production, and x1∗=(k1w+k0)γ/(k2δw)x_1^*=(k_1w+k_0)\gamma/(k_2\delta w) depends on w. Add a second sink for the output, −ℓx1-\ell x_1, and the output depends on w again (A16). At those constants, a tenfold input step then moves the steady output by −47.4% with a saturating removal γKx2/(K+x2)\gamma Kx_2/(K+x_2) at K=20K=20, by −30% with a leak k0=0.5k_0=0.5, and by +81.8% with a load ℓ=1\ell=1 (Figure 30, model predictions).

Lecture 9's two implementations adapted where their effective orders nearly matched. Degradation adapted only while the degrader stayed free and below KdK_d, and repression only while the repressor exceeded KdK_d and its promoter total (Lecture 9, §6). Those windows are where the effective orders approximately match, not where they are exactly equal.

Check an incoherent feedforward loop for exact adaptation by its reaction orders, not its constants: in the simplest loop the input must enter both paths at one order, and the degrader must act on the output at the order of its own removal. Expect a saturated removal, a leak or a second sink to break it.

A natural feedforward adapter. Is there a natural circuit that adapts perfectly by an incoherent feedforward loop, with its molecules known? Ras activation in Dictyostelium chemotaxis has been proposed. Takeda and colleagues stepped the chemoattractant cAMP and followed activated Ras through a reporter, RBD-GFP, that moves from the cytosol to the membrane, so the measured cytosolic signal falls and then returns. It returned to its prestimulus level within 35 s for steps from 10−210^{-2} to 10310^3 nM. Of the two simple topologies that can adapt perfectly, only the incoherent feedforward model fitted the data, in particular because the integral-feedback model's adaptation kinetics depended strongly on the step size, unlike the data.20 Read that result within its limits. It is a model-fitting result that compares only the tested feedback models. The roles of the activator RasGEF and the inhibitor RasGAP are inferred from the fit, and the authors keep open that adaptation happens upstream of RasGEF. Their latrunculin B test removes feedback through actin, and it is not a test of a load on the output. Which of the three experiments of A17 would settle the wiring?

Input cancellation can hide an error-integrating coordinate. In the incoherent feedforward loop, a combination of the output and the degrader changes at a rate proportional to the error. A17Compare exactness, feasibility and operating range

Assess adaptation with three separate tests: an identity of the stated model, the validity of any kinetic approximation, and a reachable, stable operating range. Lecture 8's regimes organize the limiting laws, but an identity can stay exact while feasibility or stability fails. Sorting each mechanism this way names the experiment that would break it.

The sortIdentity, limiting law, operating range

Some exactness is an identity of the stated model. The sequestering pair's subtraction (E7) holds at every binding allocation. The incoherent feedforward loop's matched orders give the same steady output (E9) for every constant positive input, an identity of its rate laws (E8). At zero input the degrader decays to zero and the output stops wherever it happens to be, so that argument needs the input positive.

Some exactness is a limiting law, created by a kinetic approximation. Zero order in a saturated cycle, the joint regime of the two-cycle feedback circuit and the approximately matched effective orders of Lecture 9's binding implementations are such laws. Lecture 8's regimes organize them. Each law holds until its approximation fails: the methylation sites fill, or an enzyme leaves saturation.

A regime justifies a limiting law, and each measured quantity then has its own range. At set PT the two-cycle feedback circuit's joint regime runs from qI=0.052q_I=0.052 to 20. The partial pool A∗+C3A^*+C_3 stays within 5% of σ\sigma from 0.065 to at least 10410^4, far past the regime's upper edge. The full total stays within 5% only from 0.064 to 5.23. Each quantity's accuracy comes from the exact decomposition (E16), so leaving the regime does not by itself end the partial pool's adaptation (A13, optional A7).

Either kind needs a feasible, stable operating range. The set point must be reachable and the rest must be stable. That range is not automatically one of Lecture 8's winner regimes, and an identity can stay exact while feasibility or stability fails, as windup and the two-stage instability show.

The capabilityFive questions place any adaptive circuit

Five questions place any adaptive circuit. Name its memory. Name the quantity that adapts. Say whether its exactness is an identity or a limiting law. Say what bounds it. And name the experiment that would break it. The table above answers them for the mechanisms of this lecture.

Lecture 11 makes the order statements systematic. This lecture used reaction orders by intuition: a zero-order removal makes an integrator inside an operating range, and an incoherent feedforward loop adapts when the orders of its rate laws satisfy one product condition. Each such limiting law holds only inside a regime whose edges set its range. Lecture 11 locates those regimes with reaction-order geometry. The exact identities need no regime. Their limits are reachability and stability.

Sort any adaptive circuit by its memory, the quantity that adapts, the source of its exactness (an identity or a limiting law), what bounds it, and the experiment that breaks it: add a load to the output, delete the memory, or push the input past the range.
