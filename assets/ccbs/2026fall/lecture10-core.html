The adaptation biomachine: where a persistent input goes when the output returns

An output that returns to its set point after a persistent input step leaves that input held in some other state, its memory. A cell builds that memory from molecules whose amounts cannot go negative, so the memory's chemical form decides whether the return rests on an exact identity or on an approximation with a range. Whether the rest is reachable and stable is a separate test.

Lecture 9 held a set point with high gain, and left an error behind. A repressor closed on its own gene moved its set point by only about 1/(1+H)1/(1+H) of a small relative change in growth, where H is the loop gain. That was Black's factor, read off where a steep production curve meets a removal line. Lecture 9 then showed, in one line, that the difference of two sequestering controllers integrates the error, and that an incoherent feedforward loop adapts in two implementations, each only inside a window of controller totals (Lecture 9, §6).

This lecture asks where the input goes when the output comes back exactly. The input is still there after the output returns, so some part of the system must hold it. We follow that question through four answers: an integral state, the theorem that demands one, the chemical forms such a memory can take, and a feedforward loop that hides its integral in a coordinate. Lecture 8 supplies the method, totals and the forms that win them. It also left a question about whether an adaptive enzyme design can be realized, which §6 answers.

Part 1

Where the input goes

A persistent input must be held somewhere when the output returns. An integral state holds it with no error, and a theorem says when a robust regulator needs one.

1The output forgets because something else remembers

An input steps up and stays up, and the output returns exactly to its old value. Where did the input go? One line of bookkeeping answers it for a stated kind of system: some other state has changed, and it holds the input. In Lecture 9's high-gain loop the only slow state is the output, so the output itself holds the input, as an error.

The questionA step in, a pulse out

Adaptation is a response to a step that returns. Hold an input at one value until the system rests, step it to a new value, and hold it there. The output rises, then returns exactly to its old value, while the input stays at its new one (Figure 1). That is perfect adaptation. A partial return leaves an offset, the error of adaptation, and adaptation whose error stays below a stated tolerance is called near-perfect. The question is where the input went.

The bookkeepingSome other state must change

One line of bookkeeping says where the input went, for a stated kind of system. Take a model s˙=f(s,u)\dot s=f(s,u), where s collects the model's states and u is its input. Suppose it rests at a finite steady state before the step, the input is then held at its new value, and the model settles to a finite steady state after it. Suppose also that the output is read from the state and responds to the step, so the step changes the vector field f at the old rest. Then the old rest is no longer a rest under the new input, and the new steady state differs from the old one. The output is the same at both, so the difference sits in some other state. That state holds the input, and we call it the memory.

The argument has a domain, and three cases lie outside it. It does not cover an output that feeds through the input directly, a pulse driven by the input's rate of change, or hidden variables that never settle. So it is not a theorem about every observed pulse. It is a statement about models that settle, with the output read from their state.

Lecture 9's loopThe output itself holds the input, as an error

In Lecture 9's high-gain loop the output itself holds the input. A repressor represses its own gene, and growth dilutes it. Promoter binding is fast, so the repressor total is the loop's only slow state, and it is the output. A change in production or removal moves the balance of the two, and a production curve of finite slope cannot rebalance at the same output (Figure 2). So the steady state must move, and the only state that can move is the output. It holds the input, as an error.

The size of that error is Black's factor. Write the repressed production as f(x)f(x), with x the output, and let the loop gain be H=−dln⁡f/dln⁡xH=-d\ln f/d\ln x at the set point. H is positive, because production falls as the output rises. In that model a small relative change in removal moves the set point by about 1/(1+H)1/(1+H) of it. That factor is a sensitivity to small changes. Figure 2 shows a finite, fourfold change, solved exactly, so its shifts are not given by the factor. The error is small when the loop gain is high, but never zero, because a finite slope always leaves the two crossings apart. Removing it needs a separate state that can hold the input while the output returns.

Where can a separate state hold the input without leaving an error?

2An integral rests only at zero error

Give the memory its own state, and let it change at a rate equal to the error. Then it can rest only where the error is zero, whatever the plant's constants, and at rest it holds the action that cancels the input. Whether the loop comes to rest is a separate test. The obvious alternative, a compensator that subtracts a measured copy of the input, stores nothing and needs a matched constant.

The constructionA state that changes at the rate of the error

An integral state changes at a rate equal to the error, so it can rest only where the error is zero. Take the simplest plant: an output x measured from its set point, so that x is the error, pushed by a constant disturbance d and relaxing at unit rate. That holds whatever the plant's constants are, because the plant does not appear in it. Both x and z are signed coordinates, not concentrations.

Is an integral the only robust way?

3Robust rejection needs an internal model

Must a loop that robustly rejects a constant disturbance contain an integral? Under stated hypotheses, yes. Francis and Wonham's internal model principle requires a mode at zero frequency in the controller, an integral of the error, but not one molecule that integrates. Other theorems reach an internal model from other hypotheses, so an adapting trace alone does not prove that an integrator is present.

The theoremThe controller must copy what makes the disturbance

The internal model principle answers the question for linear systems, under stated hypotheses. Francis and Wonham posed the classical regulator problem for linear, time-invariant systems: a plant and a separate controller, with disturbances produced by a known signal generator, here constants. In classroom form there are four hypotheses. The controller sees only the error. The disturbances are constants. The closed loop is stable. And regulation must survive small changes of the plant's parameters. Under these hypotheses the controller must feed back the error and contain a copy of the system that generates the disturbances (p. 460, Figure 6).1

The four hypotheses paraphrase a linear theorem, not a theorem about every chemical network. Francis and Wonham extend the result to weakly nonlinear plants only locally, near an equilibrium, with constant signals (p. 462).1 A nonlinear chemical network that adapts may or may not meet these hypotheses, and each case must be checked.

For constant disturbances that copy is a mode at zero frequency, which acts as an integral of the error. A constant d is generated by w˙=0\dot w=0, with d=wd=w. A controller holding the same mode, driven by the error e, is z˙=e\dot z=e: the integral of §2. Integral feedback has infinite gain at zero frequency, which is why it removes a constant error exactly.2

The theorem asks for a mode, not a molecule. It does not require one physical species to integrate the error with a constant gain. The mode can live in a combination of states, which §9 will need.

Other theoremsHypotheses decide what a theorem proves

Other theorems reach an internal model from different hypotheses. Sontag's 2003 theorem assumes that the system adapts to a class of signals, together with a signal-detection condition and bounded trajectories. It assumes no split into plant and controller, and no robustness requirement.3 It concludes that the system contains a subsystem that can generate those signals. So the principle is a family of theorems that answer different questions (optional A1).

An adapting trace alone does not prove that an integrator is present. A trace shows the output returning. Each theorem also needs its hypotheses checked: what the controller sees, which disturbances act, which changes of the plant are allowed, and whether the loop is stable. Memories made of molecules

A concentration cannot go negative, so a cell cannot hold a signed integral in one species. Three chemical routes go around that limit: a saturated modification cycle, a pair of species that sequester each other, and multiplicative growth. Each has its own limit. A circuit stores a signed integral in a capacitor. What can a cell use?

4A concentration cannot hold a signed integral

An electrical integrator is free, because a capacitor stores a signed charge. A concentration cannot go below zero, and a species' removal must stop when the species is gone. So no single species is an exact integrator across the whole range. Three useful routes go around it, and each has its own limit.

The obstacleA capacitor holds a signed charge, and a concentration cannot

A capacitor integrates for free, because its charge can have either sign. The charge Q on a capacitor is the integral of the current I through it, and the current can flow either way, so Q can be positive or negative (Figure 7, left). That is why the integrator of §2 is easy to build from electronics.

Bacteria use the first.

5Bacteria store the attractant in methylation

Escherichia coli adapts to attractant: after a step, its tumbling returns to its old rate while the attractant stays. The memory is receptor methylation. In Barkai and Leibler's reduced module, methylation can rest only at one receptor activity, whatever the attractant, so it integrates the activity's error. More generally, a saturated modification cycle integrates the imbalance of its two fluxes, feedback from the output makes that an error integral, and the cycle's total bounds the range.

The pathwayAttractant, kinase, tumble, and two methylation enzymes

In E. coli, attractant slows a receptor-coupled kinase, and the cell tumbles less. Attractant binds the receptor. The receptor-coupled kinase CheA slows, so less of the response regulator CheY is phosphorylated, and phosphorylated CheY is what makes the motor tumble (Figure 9, left). So a step up in attractant lowers the tumbling rate. Then the tumbling returns to its old rate while the attractant stays.

The memory is receptor methylation, set by two enzymes. CheR adds methyl groups to the receptor and CheB removes them.5 Methylation raises the receptor's activity, and attractant lowers it. In the cell, CheA also activates CheB by phosphorylating it, a regulation that Yi and colleagues keep apart from the model they analyze.6

10Exactness and operating range are separate questions

The word "exact" runs three things together: an exact identity of the stated model, a limiting law created by a kinetic approximation, and a reachable, stable operating range. Lecture 8's regimes organize the limiting laws, but an identity can stay exact while feasibility or stability fails. Sorting each mechanism this way names the experiment that would break it.

The sortIdentity, limiting law, operating range

Some exactness is an identity of the stated model. The sequestering pair's subtraction (7) holds at every binding allocation. The feedforward loop's matched orders give the same steady output (9) for every constant positive input, an identity of its rate laws (8). At zero input the degrader decays to zero and the output stops wherever it happens to be, so that argument needs the input positive.

Some exactness is a limiting law, created by a kinetic approximation. Zero order in a saturated cycle, the joint regime of the two-node design and the approximately matched effective orders of Lecture 9's binding implementations are such laws. Lecture 8's regimes organize them. Each law holds until its approximation fails: the methylation sites fill, or an enzyme leaves saturation.

A1Sontag's theorem needs no plant-controller split

§3 stated the classical principle, which assumes a controller that sees only the error and a regulation that survives small changes of the plant. Sontag's 2003 theorem reaches an internal model from adaptation itself, under different hypotheses.

Sontag assumes adaptation and signal detection, not a split or robustness. His note shows that if a system adapts to a class of external signals, in the sense of regulation against disturbances, then it must contain a subsystem that can generate all those signals. It does not assume that the regulation is robust, nor that the system is split into plant and controller. It assumes instead a signal-detection property, together with bounded trajectories.3

Signal detection is a condition on how the output sees the input. Sontag's precise condition is a uniform relative degree: a specified derivative of the output depends nontrivially on the instantaneous input. The signals are generated by a Poisson-stable exosystem, and the global result also assumes completeness and commutation of certain normalized vector fields. Theorem 1 is on p. 124, the definition of an output-driven internal model is on p. 122, eqs. (3) and (4), and Remark 3.2 on p. 125 qualifies the global result.3

The feedforward coordinate of §9 fits the output-driven form. Write y=x1−x1∗y=x_1-x_1^* for the output's error. Since z=x1−(k1/k2)x2z=x_1-(k_1/k_2)x_2, the degrader is x2=(k2/k1)(y+x1∗−z)x_2=(k_2/k_1)(y+x_1^*-z), and (10) becomes

z˙=−δk2k1 (y+x1∗−z) y,\dot z=-\frac{\delta k_2}{k_1}\,\big(y+x_1^*-z\big)\,y,(12)

which depends on y and z only, not on the input, and vanishes at y=0y=0. This exposes a constant-signal internal model without adding an edge to the reaction graph. It is not, by itself, a check of every hypothesis of Sontag's global theorem on the positive states.

Tell the two internal model theorems apart by their hypotheses: Francis and Wonham's needs a controller that sees only the error, constant disturbances, a stable loop and robustness to small changes of the plant, while Sontag's needs adaptation, bounded trajectories and signal detection instead.

A2A multiplicative memory integrates in its logarithm, while it lasts

§4's third route keeps the memory positive by making both its production and its removal proportional to its own amount. Its logarithm then integrates the error exactly, but only away from zero.

A memory that grows and shrinks in proportion to itself integrates in its logarithm. Let Z be made at rate μZ\mu Z and removed at rate θXZ\theta XZ, both composite processes. Then

exactly, for as long as Z>0Z>0. Xiao and Doyle illustrate such a constrained integral variable with a cell population and a toxin.4

Zero is absorbing, so a rest at zero proves nothing about the output. At Z=0Z=0 both rates vanish, so Z=0Z=0 is a rest whatever X is. A trajectory that reaches it stays there, and the output need not sit at μ/θ\mu/\theta. The error balance holds only on the interior Z>0Z>0, which must be shown to be where the system rests.

Use a multiplicative memory as an exact integral in ln⁡Z\ln Z on the interior, and check separately that the rest is interior: Z=0Z=0 is absorbing and carries no set point.

A3Moving the actuation to the sensor changes the noise, not the mean

§7 used the design in which the reference species drives the output. A small change moves the actuation to the sensor species. It changes the noise and the transient, and it leaves the mean's set point and the stability question where they were.

Kell, Ripsman and Hilfinger moved the actuation from the reference species to the sensor species. In their variant only the sensor Z2Z_2, instead of the reference Z1Z_1, acts on the controlled species, and it acts by repressing its production.17 Sensing is unchanged. The topology already appeared among the four controller topologies in the supplement of Briat, Gupta and Khammash (their Fig. S1).14

What improves is the noise, and stability is not proved. For idealized reference-actuated control, the noise in the controlled species is always larger than without control, while idealized sensor-actuated systems can suppress it well below that level. The earlier closed-loop ergodicity theorem strictly applies only to reference-actuated control, and ergodicity of the variant is supported by simulation only.17 Filo and colleagues showed that the variant contains a hidden proportional action, which speeds the response and counteracts the noise amplification of pure integral feedback.18

Keep four properties apart when comparing antithetic designs: adaptation of the mean, noise suppression, transient speed and stability. Sensor actuation improves the middle two and leaves the mean's set point and the stability question where they were.

Reversible binding keeps the identity for the mean, but not the ergodicity theorem. Theorem 2 is stated and proved for the annihilation reaction of eq. 1. A6Fold-change detection is a different adaptive property

Some feedforward loops have a second property beside returning to a steady output. It is a different property, and it is not the subject of this lecture.

Fold-change detection is a different adaptive property, which some incoherent feedforward loops have. A system detects fold changes when its response depends only on the fold change of its input, not on its absolute level: a signal that goes from 1 to 2 gives exactly the same output as one that goes from 2 to 4 (p. 894). Goentoro, Shoval, Kirschner and Alon showed that an incoherent feedforward loop provides it when its repressor nearly saturates the output's promoter, while the activator acts linearly, far from saturating either promoter (p. 895).19

Their loop stores the input in the repressor, as §8's loop stores it in the degrader. In their words, "the repressor Y acts as a memory of the activator X" (p. 896).19 Fold-change detection asks for more than §8's return of the steady output: the whole response must be the same for the same fold change.

Separate the return of a steady output from fold-change detection before attributing either to a feedforward loop.

Beyond the lecture clock

Questions to develop further

Open threads for extension essays and later lectures. They are not walked through in the room.

  1. A natural feedforward adapter. Is there a natural circuit that adapts perfectly by an incoherent feedforward loop, with its molecules known? Ras activation in Dictyostelium chemotaxis has been proposed. Takeda and colleagues stepped the chemoattractant cAMP and followed activated Ras through a reporter, RBD-GFP, that moves from the cytosol to the membrane, so the measured cytosolic signal falls and then returns. It returned to its prestimulus level within 35 s for steps from 10−210^{-2} to 10310^3 nM. Of the two simple topologies that can adapt perfectly, only the incoherent feedforward model fitted the data, in particular because the integral-feedback model's adaptation kinetics depended strongly on the step size, unlike the data.20 Read that result within its limits. It is a model-fitting result that compares only the tested feedback models. The roles of the activator RasGEF and the inhibitor RasGAP are inferred from the fit, and the authors keep open that adaptation happens upstream of RasGEF. Their latrunculin B test removes feedback through actin, and it is not a test of a load on the output. Which of the three experiments of §10 would settle the wiring?
  2. The chemotaxis range. How many methylation sites does a receptor offer, and where does measured adaptation fail? Does the failure sit where the zero-order law of §5 runs out of sites?
  3. Dilution as a leak. How small must the controllers' dilution be, against their production, for the sequestering pair's error to stay within a chosen tolerance, and does a faster-growing cell need a faster controller?
  4. Which pool a cell reads. If a cell reads the free form of a modified protein, which two-cycle designs make that free form adapt, rather than a partial pool (§6)?
  5. A longer plant. When does the two-stage sequestering loop settle on a stable cycle after it loses stability, rather than diverge or settle, and how does the stochastic mean behave there (A4)?
