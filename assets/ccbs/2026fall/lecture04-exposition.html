From model structure to a defensible behavior claim

A worked method for deciding what a reaction-model family permits, what one parameter choice produces, and which calculation supports each conclusion.

CCBS · EST 5053 · Fall 2026 · lecture 4 · lecturer-written exposition · study alone after the core lecture

Lecturer-written companion, released 15 September 2026 after the September 10 lecture. Álvaro’s student slides are linked separately on the course schedule. The lineage traces the methods, and the audience extension develops the Week 2 student contributions.

The core lecture asks for a map from biochemical structure to dynamical function. This exposition teaches how to build one without confusing a displayed trajectory with a conclusion about a design. A reaction mechanism, admissible state space, kinetic assumptions and parameter ranges define a model family. A numerical run chooses one member of that family and one initial state. Global geometry, local linearization and scalar certificates can instead establish statements that survive specified changes within the family.

The organizing question

Which structure supports which function, over exactly which family? A plotted trajectory is evidence for one model member and one start. A phase portrait organizes all starts in a region. A Hurwitz Jacobian proves a local claim for a strict parameter set or range. A Lyapunov function can sometimes certify a whole invariant domain and, when it is structural, a family of kinetics.

Declare four things before calculating
  1. Family: which mechanisms, signs, domains and parameter ranges are allowed to vary?
  2. Function: recovery, memory, commitment, bounded recurrence or an attracting clock?
  3. Scope: one initial state, a neighborhood, an invariant region or every admissible state?
  4. Failure mode: which omitted state, boundary violation, parameter equality or nonlinear term could invalidate the conclusion?
Part 1

Define the dynamical object

The exposition begins with technical prerequisites that the core uses later: a phase portrait is meaningful only after the variables contain enough information to determine one velocity at every state.

1Choose a state

State is not merely what can be measured. It is the present information required by the model to determine the instantaneous future.

Consider a mass attached to a spring. If only position qq is recorded, the same value of qq can occur while the mass moves left or right. Position therefore does not determine q˙\dot q. Velocity must be included. Starting from

mq¨+cq˙+kq=0,m\ddot q+c\dot q+kq=0,

Here m>0m>0 is mass, k>0k>0 is spring stiffness and c≥0c\ge0 is the damping coefficient. Define v=q˙v=\dot q and the state vector z=(q,v)z=(q,v). Then

q˙=v,v˙=−kmq−cmv,z˙=[01−k/m−c/m]z.\dot q=v,\qquad \dot v=-\frac{k}{m}q-\frac{c}{m}v, \qquad \dot z=\begin{bmatrix}0&1\\-k/m&-c/m\end{bmatrix}z. (1)

This is an exact change of representation, not an approximation. The second-order scalar equation and the two-dimensional first-order equation contain the same information. The benefit is conceptual: equation (1) assigns one vector to every point in the (q,v)(q,v) plane. Trajectories cannot cross there, because crossing would assign two future velocities to one state.1

The same state test applies to cells. Protein concentration alone may not determine its future if a promoter can be in two configurations with different production rates. One can include promoter state explicitly, include an external input as F(x,t)F(x,t), or derive an effective law by eliminating a fast hidden state. The choice changes what the model claims.

Operational state test

Hold every declared state variable fixed. If different hidden histories, inputs, or molecular configurations can still give different instantaneous derivatives, the declared state is incomplete for an autonomous model.

Choose variables that determine the model's instantaneous future, and distinguish state augmentation from an approximation.

2Convert memory into state

Higher order, delay, and hidden intermediates all express memory. State augmentation makes that memory explicit.

An nnth-order scalar equation can be written as nn first-order equations. For

q(n)=H(q,q˙,…,q(n−1)),q^{(n)}=H(q,\dot q,\ldots,q^{(n-1)}),

set z1=q,z2=q˙,…,zn=q(n−1)z_1=q,z_2=\dot q,\ldots,z_n=q^{(n-1)}. The resulting companion system is

z˙1=z2, z˙2=z3, …, z˙n−1=zn,z˙n=H(z1,…,zn).\dot z_1=z_2,\ \dot z_2=z_3,\ \ldots,\ \dot z_{n-1}=z_n, \qquad \dot z_n=H(z_1,\ldots,z_n). (2)

A finite chain of maturation steps works the same way. If immature protein P0P_0 matures through P1P_1 to fluorescent P2P_2, then the current value of P2P_2 does not reveal the pipeline already committed upstream. Retaining (P0,P1,P2)(P_0,P_1,P_2) turns the apparent memory into ordinary first-order flow.

A true fixed delay is different: its exact state is a history function, hence infinite-dimensional. A chain of intermediate states can approximate a distributed delay, but the approximation and its timescale must be declared. “Everything is first order” means that an appropriate state representation exists, not that one measured variable always suffices.

Rewrite a finite-order equation as a first-order state model, and recognize when a delay requires a history rather than finitely many variables.

3Prove the phase-line rules

For one autonomous variable, ordering makes the sign of one function almost a complete global analysis.

Let x˙=f(x)\dot x=f(x), with ff locally Lipschitz so solutions are locally unique. A fixed point satisfies f(x∗)=0f(x^*)=0. Between two consecutive roots, continuity prevents the sign of ff from changing. Therefore every nonstationary solution in that interval is monotone.

If ff is twice continuously differentiable near a simple root, Taylor expansion gives f(x∗+u)=f′(x∗)u+O(u2)f(x^*+u)=f'(x^*)u+O(u^2). To first order, u˙=f′(x∗)u\dot u=f'(x^*)u, so u(t)≈u(0)ef′(x∗)tu(t)\approx u(0)e^{f'(x^*)t}. A negative derivative attracts from both sides, while a positive derivative repels. When f′(x∗)=0f'(x^*)=0, inspect higher-order terms or the exact signs of the field.

The equation x˙=x2\dot x=x^2 shows why the three views are not redundant. Its origin attracts from the left and repels from the right. Separation gives

dxx2=dt⟹x(t)=x01−x0t.\frac{dx}{x^2}=dt \quad\Longrightarrow\quad x(t)=\frac{x_0}{1-x_0t}. (3)

The phase line predicts the direction, but only equation (3) shows that a positive initial condition escapes in finite time 1/x01/x_0. Conversely, ordering proves a result that no finite collection of traces can prove: a scalar autonomous system has no nonconstant periodic orbit. A periodic trajectory would have to return to a previous value after moving monotonically, contradicting uniqueness.

Check. For x˙=x(1−x)(x−a)\dot x=x(1-x)(x-a) with 0<a<10<a<1, use signs alone to prove that 0 and 1 attract, aa repels, and aa is the basin boundary.

Use phase-line signs to establish direction and basins, then solve or estimate the travel time when finite-time escape matters.

4Follow a saddle-node family

A bifurcation is a change in the organization of a family of vector fields, not simply a curve drawn in parameter space.

Consider the saddle-node normal form.2

x˙=f(x;r)=r−x2.\dot x=f(x;r)=r-x^2. (4)

Solving f=0f=0 gives no real fixed point for r<0r<0, one double root at r=0r=0, and two roots x±∗=±rx^*_{\pm}=\pm\sqrt r for r>0r>0. Since fx=−2xf_x=-2x, the positive branch is stable and the negative branch unstable. At the collision, fx=0f_x=0, so the hyperbolic linear test fails exactly where the topology changes.

The local return rate also becomes measurable. Write x=r+ux=\sqrt r+u near the stable branch:

u˙=r−(r+u)2=−2r u−u2,u(t)≈u(0)e−2r t.\dot u=r-(\sqrt r+u)^2=-2\sqrt r\,u-u^2, \qquad u(t)\approx u(0)e^{-2\sqrt r\,t}. (5)

Thus τrelax=(2r)−1\tau_{\mathrm{relax}}=(2\sqrt r)^{-1} diverges as the collision is approached. This is the mechanism behind critical slowing near a generic fold. In data, increased recovery time can be confounded by noise color, nonstationary forcing, sparse sampling, or a transition that is not a fold, so it is evidence to test rather than a universal alarm.4

Distinguish an equilibrium branch from a trajectory and derive the return-time divergence near a generic fold.

Part 2

Turn mechanism into a portrait

The toggle switch begins as interacting genes and binding states. Its nullclines become a family-level argument only after that biological layer has been reduced carefully and the reduction assumptions have been named.

5Open the toggle circuit

Mutual repression is a network of regulated addition and removal, not an arbitrary pair of sigmoids.

Let gene GXG_X produce repressor XX and gene GYG_Y produce repressor YY. Each protein represses the other gene. At a composite level:

GX⇝GX+X,X⇝∅,GY⇝GY+Y,Y⇝∅,Y⊣GX,X⊣GY.G_X\rightsquigarrow G_X+X,\quad X\rightsquigarrow\varnothing, \qquad G_Y\rightsquigarrow G_Y+Y,\quad Y\rightsquigarrow\varnothing, \qquad Y\dashv G_X,\quad X\dashv G_Y. (6)

The removal processes need not have the same molecular origin. If NXN_X is the molecule count and a bacterial cell grows as V(t)=V0eλtV(t)=V_0e^{\lambda t}, a protein that is stable as a molecule can still be diluted as a concentration. With production dNX/dt=ρXVdN_X/dt=\rho_XV and concentration X=NX/VX=N_X/V,

X˙=1VN˙X−NXV2V˙=ρX−λX.\dot X=\frac{1}{V}\dot N_X-\frac{N_X}{V^2}\dot V =\rho_X-\lambda X. (7)

Molecular degradation adds its own first-order contribution, so an effective removal rate can be δX=λ+kdeg,X\delta_X=\lambda+k_{\mathrm{deg},X}. This connects the circuit directly to reaction and growth bookkeeping.

Separate regulated production, molecular degradation and growth dilution before writing a gene circuit's concentration equations.

6Derive the effective repression law

A Hill term is a reduced occupancy law. Its assumptions are part of the model and should travel with the formula.

For the XX-producing promoter, let GXG_X denote the active configuration and CGXYC_{G_XY} a configuration containing that promoter and repressor YY. Suppose fast binding can be summarized by

CGXYGX=(YKY)nY,qGX=GX+CGXY.\frac{C_{G_XY}}{G_X}=\left(\frac{Y}{K_Y}\right)^{n_Y}, \qquad q_{G_X}=G_X+C_{G_XY}. (8)

Eliminate CGXYC_{G_XY} using promoter conservation:

qGX=GX[1+(YKY)nY]⟹GXqGX=11+(Y/KY)nY.q_{G_X}=G_X\left[1+\left(\frac{Y}{K_Y}\right)^{n_Y}\right] \quad\Longrightarrow\quad \frac{G_X}{q_{G_X}}=\frac{1}{1+(Y/K_Y)^{n_Y}}. (9)

If promoter redistribution is fast relative to protein accumulation and production is proportional to active occupancy, the slow protein equations become

X˙=αX1+(Y/KY)nY−δXX,Y˙=αY1+(X/KX)nX−δYY.\dot X=\frac{\alpha_X}{1+(Y/K_Y)^{n_Y}}-\delta_XX, \qquad \dot Y=\frac{\alpha_Y}{1+(X/K_X)^{n_X}}-\delta_YY. (10)

Equation (8) is an effective binding relation. The exponent can encode concerted switching, cooperative occupancy, or a phenomenological fit. It is not automatically the molecularity of one elementary collision. Independent identical sites with production only when all are empty would instead give (1+Y/K)−n(1+Y/K)^{-n}. Sequential binding, unequal sites, sequestration, and nonequilibrium promoter cycles yield still other rational functions. The reduction is useful because it states what is being compressed.

Three assumptions to audit

Check that promoter binding relaxes faster than the protein variables, that the promoter pool is conserved over the reduction window, and that the chosen occupancy state controls the composite production rate. Failure of any one can require extra state variables.

Derive an effective repression law from an explicit occupancy assumption and name the conditions under which the eliminated states can be ignored.

7Nondimensionalize and find every state

Scaling separates circuit shape from units and makes a complete equilibrium calculation possible.

Let x=X/KXx=X/K_X, y=Y/KYy=Y/K_Y, and use a common removal time τ=δt\tau=\delta t for a symmetric teaching case. Define aX=αX/(δKX)a_X=\alpha_X/(\delta K_X) and aY=αY/(δKY)a_Y=\alpha_Y/(\delta K_Y). With aX=aY=4a_X=a_Y=4 and nX=nY=2n_X=n_Y=2,

dxdτ=41+y2−x=f(x,y),dydτ=41+x2−y=g(x,y).\frac{dx}{d\tau}=\frac{4}{1+y^2}-x=f(x,y), \qquad \frac{dy}{d\tau}=\frac{4}{1+x^2}-y=g(x,y). (11)

At a symmetric equilibrium, x=y=sx=y=s and s3+s−4=0s^3+s-4=0, whose positive root is s≈1.3788s\approx1.3788. The asymmetric solutions are exact:

(x∗,y∗)=(2−3,2+3),(2+3,2−3),(x^*,y^*)=(2-\sqrt3,2+\sqrt3),\quad (2+\sqrt3,2-\sqrt3), (12)

or approximately (0.2679,3.7321)(0.2679,3.7321) and (3.7321,0.2679)(3.7321,0.2679). Substitution into both equations is essential. A point on one nullcline stops only one component and is generally still moving.

Nondimensionalize a circuit and verify every proposed equilibrium in both component equations.

8Assemble basins from nullclines

Nullclines locate the component sign changes. Their intersections and the flow between them organize the decision.

The xx-nullcline is x=4/(1+y2)x=4/(1+y^2). Below it, f>0f>0 and motion has a rightward component; above it, f<0f<0. The yy-nullcline is its reflection. Testing one point in each region determines the arrow directions without integrating.

Symmetry gives a useful proof. If x=yx=y, then f(x,x)=g(x,x)f(x,x)=g(x,x), so d(x−y)/dt=0d(x-y)/dt=0. The diagonal is invariant. Uniqueness prevents a trajectory from crossing it, and each side flows to its corresponding asymmetric expression state. Thus the diagonal is the stable manifold of the middle saddle and the basin boundary.

A steep input-output curve alone is not bistability. Bistability requires two stable invariant outcomes at the same parameter value, separated by a threshold. Hysteresis additionally concerns how the state follows branches when a parameter is swept. Gardner, Cantor, and Collins constructed a mutually repressive switch in Escherichia coli; the dimensionless system here is a transparent teaching model of the same dynamical design, not a parameter fit to that construct.3

Use nullcline signs and invariant sets to distinguish a basin boundary from a single zero-velocity component.

Part 3

Earn a local family-level claim

Linearization is a new dynamical system for displacements near one equilibrium. Writing that system explicitly reveals which wiring signs and parameter inequalities make the conclusion persist.

9Derive the linearized system

The Jacobian matrix becomes useful only after it is evaluated at a fixed point and placed inside a displacement equation.

For x˙=f(x,y)\dot x=f(x,y), y˙=g(x,y)\dot y=g(x,y), let (x∗,y∗)(x^*,y^*) be a fixed point and define the displacement vector u=(u1,u2)=(x−x∗,y−y∗)u=(u_1,u_2)=(x-x^*,y-y^*). Taylor expansion gives

u˙=Au+R(u),A=J(x∗,y∗)=[fxfygxgy](x∗,y∗),∥R(u)∥∥u∥→0.\dot u=Au+R(u), \qquad A=J(x^*,y^*)= \begin{bmatrix}f_x&f_y\\g_x&g_y\end{bmatrix}_{(x^*,y^*)}, \qquad \frac{\|R(u)\|}{\|u\|}\to0. (13)

The canonical linearized system is the separate first-order model

z˙=Az,A=[a11a12a21a22].\boxed{\dot z=Az}, \qquad A=\begin{bmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{bmatrix}. (14)

For the toggle,

J(x,y)=[−1−8y/(1+y2)2−8x/(1+x2)2−1].J(x,y)=\begin{bmatrix} -1&-8y/(1+y^2)^2\\ -8x/(1+x^2)^2&-1 \end{bmatrix}. (15)

Every sign has biological content. The diagonal entries are effective protein removal. Growth dilution alone contributes −λi-\lambda_i to the corresponding diagonal before other interactions are added. The off-diagonal entries are negative because each protein represses production of the other. Evaluating at different intersections gives different linear systems, so “the Jacobian of the model” is incomplete language unless the state is named.

Define displacement from a specified equilibrium and write the Jacobian inside the linearized dynamical system.

10Read modes and the Hurwitz rule

Eigenvalues are rates because an eigendirection turns a vector equation into one scalar exponential.

If Aw=λwAw=\lambda w and z(t)=a(t)wz(t)=a(t)w, then

a˙ w=A(aw)=λaw⟹a(t)=a(0)eλt.\dot a\,w=A(aw)=\lambda aw \quad\Longrightarrow\quad a(t)=a(0)e^{\lambda t}. (16)

For a real eigenvalue, the sign controls growth or decay along that eigendirection. For λ=σ+iω\lambda=\sigma+i\omega, the real part σ\sigma controls the envelope eσte^{\sigma t} and ω\omega controls rotation. A general solution is a sum of modes, with polynomial factors added when a matrix has nontrivial Jordan blocks.

Hurwitz rule

A matrix AA is Hurwitz exactly when Re⁡λj(A)<0\operatorname{Re}\lambda_j(A)<0 for every eigenvalue. Then z˙=Az\dot z=Az is globally exponentially asymptotically stable. If A=J(x∗)A=J(x^*) for a continuously differentiable nonlinear system, x∗x^* is locally exponentially asymptotically stable. One positive real part proves instability. A zero real part makes the first-order nonlinear test inconclusive.

The intuition is eventual decay. Every possible initial displacement is assembled from modal components. If even one component grows, a small perturbation with a projection onto it eventually leaves. If all exponential envelopes decay, polynomial prefactors cannot defeat them and every linear trajectory tends to the equilibrium. The distance need not decrease at every instant. For the nonlinear system, the remainder is smaller than linear near the equilibrium, so the strict linear stability result persists in a sufficiently small neighborhood.

Use eigenvalue real parts to test local attraction, and keep the nonlinear scope distinct from the global linear result.

11Use trace and determinant

For a real two-dimensional system, two scalar combinations classify all hyperbolic linear portraits.

τ=tr⁡A,Δ=det⁡A,λ±=τ±τ2−4Δ2.\tau=\operatorname{tr}A,\qquad \Delta=\det A, \qquad \lambda_{\pm}=\frac{\tau\pm\sqrt{\tau^2-4\Delta}}{2}. (17)

Since λ++λ−=τ\lambda_++\lambda_-=\tau and λ+λ−=Δ\lambda_+\lambda_-=\Delta, the two-dimensional Hurwitz condition is

τ<0andΔ>0.\boxed{\tau<0\quad\text{and}\quad\Delta>0.} (18)

A negative determinant forces two real eigenvalues of opposite sign, hence a saddle. With positive determinant, negative trace puts both real roots on the negative side or gives a conjugate pair with negative real part. The discriminant D=τ2−4ΔD=\tau^2-4\Delta distinguishes nodes from spirals but does not decide stability by itself.

For the two asymmetric toggle states, equation (15) has eigenvalues −1/2-1/2 and −3/2-3/2, so both are stable nodes. At the symmetric state s≈1.3788s\approx1.3788, each off-diagonal entry is −s3/2≈−1.3106-s^3/2\approx-1.3106. The eigenvalues are therefore −1±1.3106-1\pm1.3106, one positive and one negative. This is the saddle whose stable direction is tangent to the basin boundary.

The tangent is not the full separatrix. Nor does a stable Jacobian prove that every initial condition reaches that equilibrium. Those are global questions, which require invariant regions, nullclines, monotonicity, a Lyapunov argument, or another global tool.

Apply trace and determinant to classify planar linearizations without mistaking their local conclusions for a global basin argument.

12Know when first order is silent

Purely imaginary eigenvalues report the absence of first-order radial motion, not the presence of a nonlinear center.

Consider three systems written in polar coordinates:

r˙=−r3, θ˙=1;r˙=0, θ˙=1;r˙=+r3, θ˙=1.\dot r=-r^3,\ \dot\theta=1; \qquad \dot r=0,\ \dot\theta=1; \qquad \dot r=+r^3,\ \dot\theta=1. (19)

At the origin, all three have the same Cartesian Jacobian [0−110]\left[\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right] and eigenvalues ±i\pm i. Yet the higher-order radial laws make trajectories spiral inward, stay on circles, or spiral outward.

This is why the Hurwitz theorem uses strict inequalities. If an eigenvalue lies on the imaginary axis, the nonlinear remainder is no longer dominated by first-order contraction. One must calculate the relevant nonlinear terms, find a conserved quantity, construct a Lyapunov function, or apply a bifurcation theorem.

Recognize when zero real parts leave the nonlinear stability question open and choose a higher-order or global test.

Part 4

Replace a silent local test

The spring now returns. The same example that forced us to enlarge the state also supplies a global scalar whose derivative makes a conclusion that purely imaginary eigenvalues cannot.

13Make energy a certificate

A Lyapunov function is a generalized energy: positive away from the target and nonincreasing along the actual vector field.

For the spring state in equation (1), define

E(q,v)=12kq2+12mv2.E(q,v)=\frac12kq^2+\frac12mv^2. (20)

Differentiate along trajectories:

E˙=kqq˙+mvv˙=kqv+v(−kq−cv)=−cv2≤0.\dot E=kq\dot q+mv\dot v =kqv+v(-kq-cv)=-cv^2\le0. (21)

When c=0c=0, equation (21) gives E˙=0\dot E=0. Every nonzero start remains on its energy ellipse, so the origin is stable but not attracting. The purely imaginary eigenvalues are consistent with this conclusion, but energy proves it globally for the linear spring.

When c>0c>0, EE is positive definite and nonincreasing. The derivative is not strictly negative: it vanishes on the entire line v=0v=0. To finish correctly, inspect that set. If v=0v=0 but q≠0q\ne0, then v˙=−(k/m)q≠0\dot v=-(k/m)q\ne0, so the trajectory immediately leaves. The largest invariant set inside {E˙=0}\{\dot E=0\} is only (0,0)(0,0). LaSalle's invariance principle then gives convergence to the origin.

Lyapunov checklist
  1. Shift the candidate equilibrium to the origin.
  2. Show V(0)=0V(0)=0 and V(z)>0V(z)>0 away from it in the stated domain.
  3. Compute V˙=∇V⋅F\dot V=\nabla V\cdot F from the full nonlinear equations.
  4. If V˙<0\dot V<0 away from the origin, conclude asymptotic stability locally, or globally if the domain and level sets support it.
  5. If only V˙≤0\dot V\le0, find the largest invariant subset of {V˙=0}\{\dot V=0\}.

Positive definiteness and decreasing derivative are local unless more is shown. A global conclusion generally needs a forward-invariant domain and compact sublevel sets, often supplied by radial unboundedness. A Lyapunov function proves a statement about trajectories. Merely calling a scalar “energy-like” proves nothing. Modern biochemical-network methods construct such certificates from network structure rather than guessing a mechanical energy.78

Check the invariant zero-derivative set and confinement conditions before inferring convergence from an energy balance.

14Work the nonlinear pendulum

The pendulum shows what local linearization captures, what global energy adds, and why the angle's topology matters.

Measure angle θ\theta from the downward vertical and scale time so g/L=1g/L=1. The ideal pendulum is

θ˙=ω,ω˙=−sin⁡θ.\dot\theta=\omega,\qquad \dot\omega=-\sin\theta. (22)

Its energy per unit mL2mL^2 is

H(θ,ω)=12ω2+1−cos⁡θ,H˙=ω(−sin⁡θ)+sin⁡θ ω=0.H(\theta,\omega)=\frac12\omega^2+1-\cos\theta, \qquad \dot H=\omega(-\sin\theta)+\sin\theta\,\omega=0. (23)

At (θ,ω)=(2πn,0)(\theta,\omega)=(2\pi n,0), the Jacobian is [01−10]\left[\begin{smallmatrix}0&1\\-1&0\end{smallmatrix}\right], so small oscillations have eigenvalues ±i\pm i and period 2π2\pi. Energy supplies the missing nonlinear result: nearby sublevel sets surround the equilibrium, so it is Lyapunov stable, while conservation prevents attraction.

At ((2n+1)π,0)((2n+1)\pi,0), the lower-left Jacobian entry changes to +1+1, giving eigenvalues ±1\pm1 and a saddle. The energy there is H=2H=2. Levels below 2 librate around a downward equilibrium, the level 2 contains the separatrices, and levels above 2 rotate. The small-angle approximation captures the local period and ellipses, but it cannot display the upper saddle, the separatrix, amplitude-dependent period, or rotation.

Because θ\theta and θ+2π\theta+2\pi are the same physical orientation, the natural phase space is a cylinder rather than an infinite plane. Repeated copies in the figure are a drawing convention, not distinct pendulums.

Use pendulum energy and the cylindrical state space to distinguish oscillation, rotation and the separatrix beyond the small-angle approximation.

15Stabilize the inverted pendulum

The same state-space and Hurwitz tools turn an unstable mechanical equilibrium into a transparent feedback design.

Let ϕ\phi be angle from the upright position, and let aa be a signed horizontal pivot acceleration chosen so that

Lϕ¨=gsin⁡ϕ+acos⁡ϕ.L\ddot\phi=g\sin\phi+a\cos\phi. (24)

Near ϕ=0\phi=0, with ω=ϕ˙\omega=\dot\phi,

ddt[ϕω]=[01g/L0][ϕω]+[01/L]a.\frac{d}{dt}\begin{bmatrix}\phi\\\omega\end{bmatrix} =\begin{bmatrix}0&1\\g/L&0\end{bmatrix} \begin{bmatrix}\phi\\\omega\end{bmatrix} +\begin{bmatrix}0\\1/L\end{bmatrix}a. (25)

Without control the eigenvalues are ±g/L\pm\sqrt{g/L}, so the upright equilibrium is a saddle. Passive velocity damping alone changes the trace but leaves a negative determinant, hence it cannot remove the unstable direction. Use local proportional-derivative feedback

a=−kpϕ−kdω.a=-k_p\phi-k_d\omega.

The closed-loop linearized matrix is

Acl=[01(g−kp)/L−kd/L],tr⁡Acl=−kdL,det⁡Acl=kp−gL.A_{\mathrm{cl}}= \begin{bmatrix}0&1\\(g-k_p)/L&-k_d/L\end{bmatrix}, \qquad \operatorname{tr}A_{\mathrm{cl}}=-\frac{k_d}{L},\quad \det A_{\mathrm{cl}}=\frac{k_p-g}{L}. (26)

Hurwitz therefore requires kd>0k_d>0 and kp>gk_p>g. Proportional action stronger than gravity flips the effective stiffness; derivative action supplies contraction. With kd=0k_d=0 the linearized system is a center, not an attractor. For the smooth nonlinear model, strict Hurwitz stability proves local exponential stability. It does not prove global recovery because the trigonometric dynamics, finite track, actuator saturation, and unmodeled cart dynamics limit the basin.

Design check. Let L=1L=1, g=9.8g=9.8, kp=19.8k_p=19.8, and kd=4k_d=4. Then τ=−4\tau=-4, Δ=10\Delta=10, and D=−24D=-24. The local closed-loop portrait is a stable spiral.

Design a locally stabilizing feedback from trace and determinant, then state which nonlinear and actuator limits remain outside that guarantee.

Part 5

Stress-test recurrence against chemistry

Energy distinguishes neutral recurrence from attraction. Saturation can destroy a conserved family and leave an isolated periodic orbit. Chemistry then restricts which mathematical portraits are admissible at all.

16Separate a center from a limit cycle

Closed trajectories can mean a continuum of conserved levels or one isolated attracting orbit. The distinction is dynamical, not visual.

The ideal spring and pendulum have centers. Every nearby energy value produces a different closed orbit. Perturbing one orbit moves the trajectory onto another; it does not return to the first. By contrast,

r˙=r(1−r),θ˙=ω>0\dot r=r(1-r),\qquad \dot\theta=\omega>0 (27)

has an isolated periodic orbit at r=1r=1. Starts with 0<r<10<r<1 move outward and starts with r>1r>1 move inward. Both converge to the same orbit, making it a stable limit cycle.

For a smooth planar flow, the Poincaré-Bendixson theorem gives a proof pattern. Find a compact forward-invariant region, exclude fixed points from the limiting set, and conclude that a periodic orbit remains. It does not apply directly to a three-state repressilator or to a delay equation. A closed-looking numerical trace alone also does not invoke the theorem. Vary the step size and initial conditions, integrate long enough to remove transients, and identify the trapping and exclusion arguments.

Distinguish an isolated attracting cycle from a conserved family and state the hypotheses needed for a planar recurrence theorem.

17Find the Lotka-Volterra integral

The classic predator-prey model looks oscillatory, but its hidden conserved function shows that the orbits form a center rather than an attracting clock.

x˙=x(α−βy),y˙=y(−γ+δx),α,β,γ,δ>0.\dot x=x(\alpha-\beta y), \qquad \dot y=y(-\gamma+\delta x), \qquad \alpha,\beta,\gamma,\delta>0. (28)

The positive equilibrium is (x∗,y∗)=(γ/δ,α/β)(x^*,y^*)=(\gamma/\delta,\alpha/\beta). Define

V(x,y)=δ[x−x∗−x∗ln⁡xx∗]+β[y−y∗−y∗ln⁡yy∗].V(x,y)=\delta\left[x-x^*-x^*\ln\frac{x}{x^*}\right] +\beta\left[y-y^*-y^*\ln\frac{y}{y^*}\right]. (29)

Since u−u∗−u∗ln⁡(u/u∗)≥0u-u^*-u^*\ln(u/u^*)\ge0 for u>0u>0, VV is positive relative to the equilibrium. Its derivative cancels exactly:

V˙=δ(1−x∗x)x˙+β(1−y∗y)y˙=δβ(x−x∗)(y∗−y)+βδ(y−y∗)(x−x∗)=0.\begin{aligned} \dot V &=\delta\left(1-\frac{x^*}{x}\right)\dot x +\beta\left(1-\frac{y^*}{y}\right)\dot y\\ &=\delta\beta(x-x^*)(y^*-y) +\beta\delta(y-y^*)(x-x^*)=0. \end{aligned} (30)

Thus the positive equilibrium is surrounded by a family of conserved closed curves. The Jacobian also has purely imaginary eigenvalues, but equation (30) supplies the nonlinear reason. The model is not a robust oscillator: changing the initial condition changes the orbit and period, and common ecological modifications destroy the integral.

18See how saturation creates a cycle

A saturating predation rate changes the fixed point from a center to an unstable spiral and permits an isolated attracting orbit.

Replace linear prey growth with logistic growth and let predation saturate. Consider the following illustrative system.

x˙=αx(1−xK)−βxy1+x,y˙=−γy+δxy1+x.\dot x=\alpha x\left(1-\frac{x}{K}\right)-\frac{\beta xy}{1+x}, \qquad \dot y=-\gamma y+\frac{\delta xy}{1+x}. (31)

Use α=γ=1\alpha=\gamma=1, β=δ=3\beta=\delta=3, and K=3K=3. The positive fixed point is

(x∗,y∗)=(12,512),J(x∗,y∗)=[1/9−15/90].(x^*,y^*)=\left(\frac12,\frac5{12}\right), \qquad J(x^*,y^*)=\begin{bmatrix}1/9&-1\\5/9&0\end{bmatrix}. (32)

Here τ=1/9>0\tau=1/9>0 and Δ=5/9>0\Delta=5/9>0, with eigenvalues 1/18±i179/181/18\pm i\sqrt{179}/18. The coexistence point is an unstable spiral. The positive quadrant is invariant. Logistic prey growth bounds xx, and d(x+y)/dt=2x−x2/3−(x+y)d(x+y)/dt=2x-x^2/3-(x+y) bounds the total. The computed trajectories in Figure 11 approach the same orbit from both sides. A Poincaré-Bendixson proof would additionally need an interior trapping argument excluding equilibria from the limiting set. That final global proof is not supplied by the local eigenvalues or by the figure alone.

What the computation establishes

The figure is strong evidence for an attracting cycle for the displayed parameters and solver checks. It is not by itself a proof of uniqueness over all parameters. The analytic claim should name the invariant region and theorem; the numerical claim should archive equations, parameters, initial conditions, tolerances, and convergence tests.

19Solve two reaction-network portraits

Small mass-action networks connect bifurcation and basin geometry directly to stoichiometric events.

Chemical admissibility test

Before transferring a mathematical portrait to concentrations, check three structural restrictions. Positivity: on the face xi=0x_i=0, the component Fi(x)F_i(x) must be nonnegative, so flow cannot leave the nonnegative orthant. Independent parameters: distinct elementary reactions have independent positive constants unless a declared mechanism couples them; exact equality between unrelated rates is tuning, not structure. Kinetic form: elementary mass action has

F(x)=Γv(x),vj(x)=kj∏ixiαij,kj>0,F(x)=\Gamma v(x),\qquad v_j(x)=k_j\prod_i x_i^{\alpha_{ij}},\qquad k_j>0, (33)

so its polynomial signs are tied to what each reaction consumes and adds. Hill and Michaelis–Menten functions can escape that elementary polynomial form only as effective laws whose eliminated states and timescale assumptions remain attached.

A. A square-root response is a saddle-node slice

Treat XX as a clamped input and let the two reactions be

X→k1X+Y,2Y→k2Y,X\xrightarrow{k_1}X+Y,\qquad 2Y\xrightarrow{k_2}Y,

The rate constants are independent and positive. Choose each as one in this scaled illustration. The resulting scaled rates xx and y2y^2 give

y˙=x−y2.\dot y=x-y^2. (34)

For x>0x>0, the physical equilibrium is y∗=xy^*=\sqrt x, with derivative −2x<0-2\sqrt x<0. The other algebraic root lies outside the concentration domain. As x↓0x\downarrow0, the return time diverges as 1/(2x)1/(2\sqrt x). This is the saddle-node normal form restricted by nonnegativity, and it shows why the state domain belongs in the analysis.

B. A mass-action winner-take-all network

X+Y→k12Z,Z+X→k22X,Z+Y→k32Y.X+Y\xrightarrow{k_1}2Z,\qquad Z+X\xrightarrow{k_2}2X,\qquad Z+Y\xrightarrow{k_3}2Y. (35)

For the chosen equal unit rate constants,

x˙=x(z−y),y˙=y(z−x),z˙=2xy−zx−zy.\dot x=x(z-y),\qquad \dot y=y(z-x),\qquad \dot z=2xy-zx-zy. (36)

The positive total T=x+y+z>0T=x+y+z>0 is conserved, so every trajectory stays on one simplex. This restriction to a positive stoichiometric class is fundamental in mass-action dynamics.5 Set z=T−x−yz=T-x-y to obtain the two-dimensional system

x˙=x(T−x−2y),y˙=y(T−2x−y).\dot x=x(T-x-2y),\qquad \dot y=y(T-2x-y). (37)

The equilibria in the triangle are (x,y)=(0,0)(x,y)=(0,0), (T,0)(T,0), (0,T)(0,T), and (T/3,T/3)(T/3,T/3). The first is a source, the two winner vertices are stable nodes, and the interior point is a saddle with eigenvalues −T-T and T/3T/3. One identity explains the choice:

ddt(x−y)=z(x−y).\frac{d}{dt}(x-y)=z(x-y). (38)

The sign of x−yx-y is preserved and its magnitude is amplified whenever z>0z>0. Positive equal initial competitors stay on the invariant diagonal and approach the saddle. The all-ZZ vertex remains stationary. Any imbalance selects a winner. This is bistability built from elementary reactions, a conservation law, and positive invariance, without placing a Hill function into the model by hand. Related monotonicity tools extend order-based conclusions to much larger biochemical systems.6

20Reuse the complete workflow

A defensible phase portrait is a reproducible argument whose biological, geometric, local, and global layers agree.

  1. Function and scope. State the behavior: local recovery, two basins, a conserved family, finite-time escape, or an attracting cycle, and name the region over which it is claimed.
  2. Family. State which mechanisms, signs, kinetic shapes and parameter ranges are fixed, and which are allowed to vary.
  3. State. List variables, units, domain, external inputs, conserved totals, and any hidden variables removed by approximation.
  4. Mechanism. Connect every addition, removal and regulatory sign to a reaction or declared effective law.
  5. Global geometry. Find every scalar root or planar nullcline, label component signs, and mark invariant boundaries before integrating.
  6. Local system. At every fixed point write A=J(x∗)A=J(x^*) and the actual approximation z˙=Az\dot z=Az.
  7. Strict test. Apply Hurwitz only when every eigenvalue has negative real part. Record positive or zero real parts separately.
  8. Global certificate. Search for energy, a Lyapunov function, a conserved quantity, a trapping region, monotonicity, or stoichiometric structure.
  9. Chemical audit. Check positivity, parameter independence, mass-action sign constraints and the assumptions behind every effective law.
  10. Numerical audit. Compare several initial conditions, vary the time step and horizon, and preserve the code and parameters that generated every curve.9
  11. Scope sentence. End with what has been proved, where it holds, and what remains an inference or hypothesis.

Four transfer exercises, with answers

1. A linear biochemical pair. For A=[−2−31−1]A=\left[\begin{smallmatrix}-2&-3\\1&-1\end{smallmatrix}\right], classify the fixed point. Answer: τ=−3\tau=-3, Δ=5\Delta=5, and D=−11D=-11, so it is a stable spiral with eigenvalues (−3±i11)/2(-3\pm i\sqrt{11})/2.

2. A semidefinite derivative. Why does V˙=−x2\dot V=-x^2 not alone prove convergence to the origin in a two-state system? Answer: the derivative vanishes on the whole line x=0x=0. One must determine the largest invariant subset of that line. It may be the origin, another trajectory, or a continuum of equilibria.

3. Center or cycle. Two initial conditions produce distinct closed curves that remain separated forever. Which object is supported? Answer: a center or another conserved family, not an attracting limit cycle. Perturbations do not converge back to one isolated orbit.

4. Toggle perturbation. A pulse moves a state close to the diagonal but not across it. Does the cell switch in the deterministic symmetric model? Answer: no. The diagonal is the invariant separatrix. The state returns to the attractor in its original basin. With noise, boundary crossing becomes probabilistic and requires a stochastic model.

Competence test

You can now take a reaction-model family from structure to function: choose a sufficient state, identify the invariant geometry, write the explicit local system, apply a strict stability rule, add an energy or structural argument when first order is silent, and distinguish what the family guarantees from what one simulation merely displays.

Build a reproducible dynamical argument whose mechanism, state space, local tests, global claims and numerical checks agree.
